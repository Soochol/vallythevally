# 네이버 재무: 의미와 복기 한계

확인일 **2026-11-08**(전 항목). 부모 quarter 표본·finance-probe를 읽고 이 메모만 작성했다.

| 확인 대상 | 성공·확인 범위 | 미확인·적용 한계 |
|---|---|---|
| [응답 A][A] | 무인증 HTTP 200 재확인. 삼성전자 표본은 6기간·16행. `202609`는 `isConsensus:Y`, 나머지 5열은 N. | Y는 [화면 배포 코드 B][B]에서 전망치 표식에 연결된다. N은 최초 공시본·감사 완료 보증이 아니다. |
| [화면 C][C]·B | HTML 200이나 재무 본문은 로딩 상태. 연결된 JS에서 단위 ‘억원, %, 배, 원’, 누적값 차감 방식, 최근 3개월 증권사 전망 평균 설명을 확인했다. | 브라우저 호스트 불가로 렌더·툴팁 미검증. |
| [공급자 D][D] | FnGuide 표는 별도/연결 선택과 분기 순액, 분기 ROE/ROA/PER/PBR의 직전 4분기 연환산을 설명한다. | SJM 일반 안내다. 삼성전자는 502/연결 초기화로 실패; 모바일 16행 산식 대사는 미완료. |

**16행의 단위·기간을 분리해야 한다.** 매출액·영업이익·당기순이익·지배주주순이익·비지배주주순이익(5)은 억원, 영업이익률·순이익률·ROE·부채비율·당좌비율·유보율(6)은 %, EPS·BPS·주당배당금(3)은 원, PER·PBR(2)은 배로 분류하는 매핑이다. B·D 기준의 단위 분류이며 JSON 행별 메타는 아니다. 분기 손익·EPS, 결산시점 자본/비율, 4분기 연환산 지표를 모두 ‘해당 분기 실적’으로 그리면 안 된다. ROA는 표본에 없다.

**연결·공개일·수정본.** B의 기업개요에는 ‘출처 : 에프앤가이드’가 있지만 A는 공급자·연결/별도 식별자를 주지 않는다. 기업개요 출처를 재무행 전체로 확장하지 않는다. 표본의 `key/title`은 결산월이고 `value/cx`에는 공시접수번호·`published_at`·정정일·버전이 없다. D는 공시 뒤 서비스 반영에 2~10영업일이 걸릴 수 있다고 안내한다.

**2020~22 복기 판정.** 부모 probe의 과거 날짜 인자 시험도 최신 기간을 반환했다. 최신 표의 정정·자본변동 소급값·컨센서스 혼재로 당시 원천에 바로 쓰기 어렵다. Y열 제외만으로 해결되지 않는다. 최초 공시/잠정발표 원문과 수정본을 따로 보존하고, 결산기간·연결범위·발표시각·접수번호를 연결해 그 시점까지 알려진 버전만 표시해야 한다. 확보 전에는 ‘당시 수치 미복원’으로 남긴다.

**제공 안내 확인.** [네이버 공식 FAQ E][E]는 콘텐츠 제공사와의 유료 계약을 설명하고 “제3자에게 재배포하는 것은 금지되어 있습니다”라고 명시하며 개인 프로그램·웹페이지 재가공도 금지한다고 안내한다. D 하단은 “모든 콘텐츠에 대한 저작권은 FnGuide에” 있다고 표시하고 시간 경과에 따른 변경 가능성을 안내한다. 원문 확인이며 법률판단은 아니다. 응답 성공은 공식 API 지원·재배포 허락을 뜻하지 않는다.
