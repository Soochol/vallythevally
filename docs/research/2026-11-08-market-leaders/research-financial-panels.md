# 재무 보조패널 조사 메모

확인일: **2026-11-08**(아래 모든 직접 링크 공통). 결론은 **조건부 가능**이다. 주가 아래 분기 실적 패널을 같은 날짜축으로 배치하되, 회계기간 종료일과 실제 공개일을 분리해야 한다. 당시 정보 화면은 공개 이후부터 계단형으로 표시하고 이전은 결측 처리한다. 이는 표시·수집 설계 제안이며 기존 HTML의 구현 가능성을 실행 검증한 결과나 예측 신호는 아니다.

**확보 경로 — 문서 확인, API 실데이터 미확인.** [OpenDART 전체 재무제표 가이드][A]는 `fnlttSinglAcntAll`에 2015년 이후 사업연도를 명시하므로 2019~2023은 문서상 포함된다. 40자리 `crtfc_key`, 8자리 `corp_code`, 사업연도, 보고서 코드, `fs_div`가 필수다. 코드는 Q1 `11013`, 반기 `11012`, Q3 `11014`, 연간 `11011`; 연결 `CFS`를 우선하고 별도 `OFS`와 섞지 않는다. 8개 사례의 전 분기 존재·계정 대응은 아직 확인하지 않았다. 인증키 탐색·사용과 재무 API 호출은 하지 않았다.

**금액 해석 — 문서 확인, 파생 계산은 제안.** [가이드][A]의 `thstrm_amount`는 분·반기 **IS/CIS에서 3개월 금액**, `thstrm_add_amount`는 당기누적금액이다. 이 규칙을 CF까지 확장하면 안 된다. [IAS 34 §20(d)][B]의 중간 현금흐름표는 연초 이후 누적이므로 기간을 원문으로 확인한 후 Q2=반기−Q1, Q3=9개월−반기로 구한다. 반면 [LG화학 IR p.17][F]는 단독분기와 연간 CF를 병기하므로 재차 차감하지 않는다. Q4=연간−9개월은 동일 연도·통화·연결범위·계정·계속/중단영업 기준 및 정정 버전이 맞을 때만 허용한다. 중간 추정 변경도 차액에 포함될 수 있어 순수한 사업 변화로 해석하지 않는다. Q4는 두 입력 중 늦은 공개일 이후 표시하고, 계정 누락·비교 불가는 0 대신 결측으로 둔다. 실제 DART CF 변환·Q4 대조는 미검증이다.

**당시 시점 — 경로 확인, 정정 이력 복원 미검증.** [공시검색][C]의 `rcept_dt`는 날짜뿐이며 `last_reprt_at=N`은 정정보고서를 포함한다. 최초·정정 접수번호별로 보고서명·접수일·대상기간·단위·연결범위와 [원문 ZIP][D], 원문 해시를 보존하고 그날까지 공개된 버전을 선택해야 한다. 전체 재무제표 API는 접수번호/as-of를 입력받지 않으므로 현재 조회값과 최초 접수일만 결합해서는 당시 값을 입증할 수 없다. 공시시간 미확인 시 다음 거래일부터 표시하는 보수적 규칙이 적절하다. 더 이른 IR 잠정치는 별도 발표일·버전으로 관리한다. 원문 API도 키가 필요해 이번에는 정정 전후 수치의 실제 복원을 검증하지 않았다.

**무인증 표본 — 원자료 대조 완료.** 기존 `kospi.json`의 `kp-nv-21q1`과 [NAVER 2021-04-29 발표][E]를 다시 대조했다. 연결 매출 14,991억원·영업이익 2,888억원이 일치하고, 직접 계산한 영업이익률은 `2888/14991×100=19.26%`다. LINE 통합에 따른 비현금 처분손익 설명도 확인했다. 따라서 순이익/EPS 급증을 영업현금흐름 개선으로 치환하지 않는다. LINE 관련 중단영업·비교기간 재작성의 전체 주석 대조는 남아 있다. [LG화학 2022 사업보고서 p.3][G]는 물적분할 후 LG에너지솔루션을 종속회사로 명시하므로 분할·상장이 곧 연결 제외라는 가정도 금물이다. [IR][F]의 소급작성·감사 전 수치 경고를 함께 보존해야 한다.

| 첫 버전 판단 | 지표·계산 | 적용 조건 / 확인 범위 |
|---|---|---|
| 권장 | 분기 매출·영업이익, 영업이익률=이익/매출×100 | 연결 기준·공개일·단위 표시; NAVER 1개 분기만 실대조 [E] |
| 조건부 | 매출 YoY=(당분기/전년동분기−1)×100 | 동일 회계범위 확인; 이익은 전년 적자·0이면 증감률 대신 흑자/적자 전환·차액 |
| 조건부 | 매출·영업이익 TTM=최근 4개 단독분기 합 | 분기 4개와 버전 일치; TTM 이익률은 합계끼리 나눔, 분기 이익률 평균 금지 |
| 후순위 | 영업현금흐름 단독분기·TTM | 누적/단독분기 구분·차감 검증 후; IR과 DART 혼용 금지 [A][B][F] |
| 보류 | EPS·PER | 가격/EPS 분할 기준 일치·가중평균주식수·지배주주이익 확인 필요; EPS≤0이면 PER은 ‘산출 부적합’, 0배 금지 |

표의 판단은 연구 설계 제안이다. [카카오 공고][H]의 500원→100원 분할을 확인했지만 기존 가격 공급자의 조정식과 EPS의 분할 반영을 대조하지 않아 PER은 보류한다. YoY·TTM을 2019-07부터 채우려면 2018년 자료도 필요하며, 차트 종료일 이후 발표된 값은 소급 삽입하지 않는다. 이번 범위는 공식 문서와 IR 표본 확인이며 전체 재무 수집·정정 원장 구축·HTML 변경은 하지 않았다.
