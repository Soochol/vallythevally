## 계산과 수집 검증

```sh
/usr/bin/python3 docs/research/2026-11-08-market-leaders/fetch-kospi.py
/usr/bin/python3 docs/research/2026-11-08-market-leaders/kospi-build.py
/usr/bin/python3 docs/research/2026-11-08-market-leaders/fetch-kospi.py --check
/usr/bin/python3 docs/research/2026-11-08-market-leaders/fetch-kospi.py --audit-sources
```

네트워크 없는 재현은 첫 명령에 `--offline`을 붙인다. 데이터 갱신은 공급자가 과거 자료를 변경할 수 있으므로 기존 원본을 별도 보존한 뒤 시행한다. 이 경로의 코드·자료만 작성했으며 서버·자격증명을 사용하지 않는다.

- `fetch-kospi.py`: 공개 API GET, 원본 저장, SHA-256 기록, NAVER 최종 시계열 구성, Yahoo 불일치 기록, 정점·하락률·상대가격 계산, 검증.
- `kospi-build.py`: 원문에서 확인한 사실·해석·출처를 구조화하고 `kospi.json`, `kospi.md` 생성.
- `kospi-raw-*-naver.txt`, `kospi-raw-*-yahoo.json`: 조회 원본. 최종 시계열은 NAVER 원본 하나만 따른다.
- `kospi-price-manifest.json`: 실제 열린 API URL, 날짜 범위, 건수, SHA-256.
- `kospi-price-checks.json`: 공급자 대조와 불일치의 날짜·각 종가를 전부 보존. 차이를 평균내거나 보간하지 않는다.
- `kospi-metrics.json`: 각 사례·지수의 직접 계산값. `kospi.json` 안의 metrics와 동일한지 `--check`가 확인한다.
- `kospi-validation-log.json`: 마지막 자체 검증 출력.

- `kospi-source-audit.json`: 출처 URL을 실제 다시 연 HTTP 결과, 응답 바이트 수와 SHA-256. 문서 의미의 자동 검증을 뜻하지 않는다.

식: `정점→종료 변화율 = (종료 종가 / 정점 종가 - 1) * 100`; `상대가격 변화율 = ((종목 종료/시작) / (지수 종료/시작) - 1) * 100`. 비율 계산은 원자료 정밀도로 수행하고 표에서 소수 둘째 자리로 표시한다.

예: 삼성전자 `(55,300 / 91,000 - 1) × 100 = -39.230769%`; NAVER `(177,500 / 454,000 - 1) × 100 = -60.903084%`. LG화학 `(600,000 / 1,028,000 - 1) × 100 = -41.634241%`; 카카오 `(53,100 / 169,500 - 1) × 100 = -68.672566%`.

검증은 날짜 정렬·중복·양수, 보존 원본으로부터 산출 JSON 재계산 일치, 사건 3~5개, 네 사례, 참조 sourceId 유효성, asOf 날짜 범위를 확인한다. 웹 사실의 의미와 발표일은 직접 읽어 검토했다. 이 검증은 데이터 공급자 원장의 완전성이나 인과관계를 증명하지 않는다.

## 조사 방법

- 대상은 우선 후보 삼성전자·NAVER·LG화학과 비교 사례 카카오의 목적 표본이다. 전 종목 모집단·생존편향 보정·시가총액 기여 순위를 조사하지 않았다.
- 주요 사건 연구 기간은 2020-01-01~2022-12-31이다. 가격은 완충 구간을 포함해 2019-07-01~2023-06-30 전체를 수집했다. 관측 종료 후의 성과는 추정하지 않았다.
- 최종 차트 입력은 NAVER 금융 공개 API 과거 종가, 조회 시점은 2026-11-08이다. KOSPI는 가격지수 포인트이며 주식은 원 단위이다. 현재 제공되는 기업행사 조정 시계열이고 당시 원시 호가 테이프가 아니다.
- 현금배당을 따로 더하거나 재투자하지 않았다. NAVER 세부 조정식과 현금배당 조정 포함 여부의 공급자 문서는 확보하지 못했다. 따라서 총수익률·배당 포함 수익률이라 부르지 않고 공급자 종가 변화율로 제시한다.
- Yahoo chart API의 quote.close·adjclose·기업행사 원본을 비교용으로 보존했다. 최종 계산에 adjclose는 쓰지 않았고, Yahoo의 거래량 0 반복값 및 일부 다른 종가 때문에 최종 차트 원천으로 채택하지 않았다. 두 공급자의 가격을 혼합하거나 결측을 보간하지 않았다.
- NAVER 거래량 0 행을 제외했다. 카카오 2021-04-12~14는 회사 공고의 거래정지 일정과 맞는다. Yahoo와 날짜 목록도 달라 최종 관측 건수는 NAVER를 따른다. 거래일의 휴장 여부를 KRX 캘린더 전체와 별도 대조하지는 않았다.
- 기간 정점은 2020~2022년 모든 관측 거래종가의 최댓값이다. 장중 고가나 상장 이후 역대 최고가가 아니다. 같은 최댓값이 여러 날이면 첫날을 표시하고 allDates에 모두 보존한다.
- 정점→기준일 변화율 = (기준일 마지막 거래종가 / 기간 정점 종가 - 1) × 100. 2022년 말은 12월 29일, 2023년 상반기 말은 6월 30일이다. 정점 뒤 저점은 정점일부터 2023-06-30까지 검색한 최저 종가이며 일반적인 전체기간 최대낙폭과 구분한다.
- 상대가격 변화율 = ((종목 기준일 종가 / 종목 시작일 종가) / (KOSPI 기준일 종가 / KOSPI 시작일 종가) - 1) × 100. 퍼센트포인트 단순 차이, 베타 조정 초과수익 또는 정밀 지수 기여도가 아니다.
- 등장·성숙·약화·상실의 구간은 차트와 공개 자료를 읽기 위한 사후 편집 구분이다. 통계적 전환점 검정이나 매매 규칙이 아니며, 경계일은 사건 인과효과의 발생일을 뜻하지 않는다.
- 사건은 실적 분기 종료일보다 실제 공개일을 사용했다. 날짜 충돌이 있으면 기록하고 더 늦은 날짜를 택했다. asOf는 해당 날짜 전에 공개된 기업 자료만 사용하며 6월 말에 아직 발표되지 않은 2분기 결과는 넣지 않았다.
- 기업 보도자료는 사실·회사 설명·회사 전망을 구분했다. 연구자의 해석에는 사후 해석을 표시하고, 당시 기대 숫자는 동시대 원문 없이 만들지 않았다. 발표 시각·시장 예상과 수급을 통제하지 않아 뉴스→가격 인과관계를 주장하지 않는다.
