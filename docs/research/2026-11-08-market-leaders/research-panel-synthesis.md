# 재무·시장 보조패널 통합 조사 결론

확인일: 2026-11-08. 조사만 수행했으며 기존 HTML·코드·시계열을 변경하지 않았다.

## 결론과 권장 배치

현재 단독 HTML에 가격 아래 재무·상대강도·시장환경 패널을 붙이는 것은 정적 구조 검토상 가능하다. 구현·렌더링 검증이나 8개 기업 전 분기 데이터 확보를 완료했다는 뜻은 아니다.

1. 주가와 선택 시장 지수의 가격 비교.
2. 분기 매출·영업이익 막대와 영업이익률 선. 금액·비율 축 구분, 적자와 결측 허용.
3. 선택 지수 대비 종목 상대강도. 기존 가격 자료 재사용.
4. 선택형 시장환경: 지수 추세/낙폭, 실현변동성, 한국은행 기준금리. 초기에는 한 항목씩 표시하며 접기 가능.

종목·시작/종료·커서 날짜는 공통으로 두고 x축을 일치시킨다. 일별 시장과 분기 재무를 날짜 교집합으로 합치지 않는다. 각 패널은 해당 빈도로 그리되 관측일·공개일·단위와 결측을 커서 값 표에서 구분한다. 재무는 분기말 막대인 사후 분석과 공개 이후의 최근 값 계단인 당시 복기를 구분한다.

## 지표별 범위

- 우선: 분기 매출·영업이익·영업이익률, 종목 RS, 시장 추세/낙폭. 기존 지수 입력은 확보했고 재무는 기업 IR 표본과 OpenDART 문서로 경로를 확인했다.
- 선택 확장: 분기 매출 YoY·최근 4개 분기 합(TTM), 일간 수익률 기반 실현변동성, 기준금리. TTM/YoY 준비구간과 단독분기/누적 정의를 고정한다.
- 차기: 원달러 매매기준율·국고채 3년. ECOS 2019·2023년 실제 표본을 확인했으나 전 기간 결측·공개시각은 미검증이다.
- 추가 검증 후: 시장별 외국인·기관 순매수, 거래대금, breadth, VKOSPI. KRX 접근·제공 범위·이용 조건과 당시 모집단이 필요하다. 여덟 사례로 breadth를 만들 수 없고 실현변동성을 VKOSPI라고 부르지 않는다.
- 후순위: 현금흐름·EPS/PER. 현금흐름 누적의 분기 변환과 EPS/가격의 분할 기준을 먼저 대조한다. 적자 PER을 0으로 표시하지 않는다.

## 시점·자료 조건

OpenDART 전체 재무제표 문서는 2015년 이후와 API 인증키 필수를 명시한다. 2019~2023년은 문서상 범위 안이나, 전 종목·전 분기 응답은 미확인이다. 인증키를 탐색하거나 사용하지 않았다. 공식 재무 원문은 연결/별도, 회계범위, 통화, 계정, 분기/누적, 최초·정정 버전을 구분한다. Q4=연간-9개월은 이 조건이 맞을 때만 계산한다.

3월 말 실적이 4월 말 발표되면 당시 복기 차트에는 공개 전 표시하지 않는다. 정정 수치를 최초 발표일에 소급하지 않고 당시 공개본을 선택한다. 공시시간 미확인 시 다음 거래일부터 반영하는 보수적 방식을 권장한다. 발표일·효력일·미국과 한국의 시간대도 구분한다. 미래 복기 시 원본이 미복원된 값은 공백으로 남긴다.

기존 HTML 413,539바이트와 native chat 한도를 고려해 분기·이벤트 원자료를 압축 저장하고 매일 같은 값으로 채운 배열은 저장하지 않는다. 새 자료 반영 후 파일 크기를 다시 확인한다.
