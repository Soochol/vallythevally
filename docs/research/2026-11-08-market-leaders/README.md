# 코스피·코스닥 주도주 연구: 2020~2022 파일럿

사용자 요청: 지수 상승 사이클을 중심으로 주도주의 탄생과 주도력 상실을 연구하고 HTML로 제공한다.

담당: 기존 Orca 워커 1 시장·지수, 워커 2 코스피, 워커 3 코스닥. 부모는 출처·수치 검토와 단독 HTML 제작·화면 검증을 담당한다. 파일 소유권은 각 brief에 명시했다.

범위: 2020~2022 핵심 분석, 가능하면 전후 6개월 가격. 선정 사례 연구이며 전 종목 순위나 매매전략 성과 검증은 아니다. 지수 기여·시장 breadth·당시 업종 가중치가 없으면 미산출로 표시한다.

완료 기준: 실제 가격과 출처, 계산 재현법, 시점별 사건 및 판단 한계, 실패 비교, 작동하는 오프라인 단독 HTML, 시장·종목 선택과 가격/상대강도 탐색, 당시 관찰과 사후 해석 구분, 모바일·일반 브라우저 검증.

## 결과

`report.html`을 일반 브라우저로 열면 된다. 별도 서버·설치·네트워크가 필요 없다. 근거 원문 링크를 열 때만 인터넷을 사용한다.

- 지수 2개, 선정 사례 8개, 일별 관측값 9,895개, 출처 항목 75개.
- 코스피: 삼성전자, NAVER, LG화학, 카카오(비교).
- 코스닥: 씨젠, 에코프로비엠, 위메이드, 수젠텍(비교).
- 전체 분석: 시장 사이클, 지수/종목 가격 변화, 지수 대비 상대강도, 비교 종목, 사후 단계 지도, 사건 타임라인, 정점 시차.
- 시점 복기: 2020·2021·2022년 6월 말까지의 차트와 공개일이 검증된 당시 메모만 제공한다. 사후 사건 해설·정점·이후 결과를 가리고, 명시적으로 펼칠 때만 결과를 표시한다. 기록을 텍스트로 다운로드할 수 있다.
- 근거: 출처별 공개일·확인일·보조자료 여부, 공급자 가격 기준과 미검증 범위를 표시한다.

‘비교 실패’는 가격 주도 지속의 실패이며 기업 사업 실패 판정이 아니다. 수젠텍을 씨젠의 시간상 후발주로 단정하지 않는다. 에코프로비엠의 2023년 재등장도 관찰해 영구 소멸과 일시적 약화를 구분한다.

## 자료와 재현

워커별 `market.md`, `kospi.md`, `kosdaq.md`가 주장별 근거와 자료 한계를 설명한다. 각 `fetch-*.py`와 원응답 파일은 수집·계산 재현용이다. 실행 옵션은 각 문서 또는 `--help`로 확인한다. 수집기는 현재 공급자 응답을 다시 읽을 수 있으므로 기존 자료를 검증하려면 각 문서의 오프라인/검사 옵션을 사용한다.

통합 HTML 재생성:

```sh
python3 docs/research/2026-11-08-market-leaders/build-report.py
```

`build-report.py`는 일별 자료로 정점·기간말 변화율을 다시 계산해 워커 보고와 대조하고, 출처 참조와 당시 메모의 공개일을 검증한다. `report-build.json`에는 입력 지문·저장소 기준 SHA·HTML 지문·건수를 기록한다. `report-data.json`은 읽기 쉬운 통합 자료다.

화면 검증:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright-core \
CHROMIUM_EXECUTABLE=/path/to/chromium \
node docs/research/2026-11-08-market-leaders/verify-report.cjs
```

실제 검증 환경과 결과는 `report-validation.json`에 기록했다. 오프라인 로딩, 알려진 지수 구간 값, 8개 사례·비교·로그축, 24개 종목/복기일 조합, 미래 정보 가림, 키보드 탐색, 기록 다운로드, 출처 필터, 1440·768·390px 화면과 테마 변경을 확인한다. 이 정적 보고서만 검증했으며 기존 앱 서버는 실행·변경하지 않았다.

## 해석 범위

사례와 단계는 사후 선정이다. 원래 기대한 전체 시장의 주도주·실패 후보 모집단 분석, 업종 전체 상대강도, 거래대금/수급 순위, breadth 및 정확한 지수 기여도는 이 파일럿에서 산출하지 않았다. 매매 규칙의 예측력 검증으로 해석하지 않는다.

주 차트 가격은 NAVER로 통일했다. 기업행사에 의해 조정된 현재 제공 과거 시계열이며 세부 배당·권리 조정 산식을 독립 감사하지 못했다. 당시 원가격 또는 동일 기준 투자자 총수익률로 부르지 않는다. 특히 카카오의 분할 전 공급자 차이, 에코프로비엠의 유상증자 권리 현금흐름 한계는 각 자료에 기록했다. 주별 선은 일별 공통 관측일을 맞춘 뒤 표시용으로 추출했고, 정점·변화율은 원 일별 값에서 계산했다.
