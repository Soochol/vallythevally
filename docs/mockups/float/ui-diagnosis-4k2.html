현재 화면 진단

fake-kiwoom 위에서 데스크톱 1440×900 23장, 휴대폰 390×844 5장을 실제로 찍어서 봤습니다. 화면 하나하나는 단정합니다. 문제는 화면끼리 규칙이 다르다는 점, 그리고 겹침 화면이 차트를 너무 쉽게 가린다는 점입니다.

핵심“차트에 미리보기 중”인데 차트가 안 보임

지표 입력창이 화면 전체를 70% 어둡게 하고 흐리게 덮습니다. 범례에 이평 20이 실제로 그려지고 있지만 사용자는 볼 수 없습니다. 검색도 마찬가지입니다.

버그새 조건식의 실행 버튼이 잘림

‘조건 추가’ 아래 실행 버튼이 윗부분만 보입니다. “KRX 일봉 없음”은 배너와 빈 상태에서 두 번 나오고, “…” 메뉴도 두 개입니다.

정보 설계재무자료: 0으로 채운 9줄

DART 키가 없으면 할 수 있는 게 없는데, 진행 표 9줄이 모두 0으로 나옵니다. 이름표와 값이 500px 떨어져 있어 줄을 따라 읽기도 어렵습니다. 같은 안내가 세 번 반복됩니다.

버그휴대폰에서 종목명이 잘림

거래소 3칸과 ‘재무자료’가 종목명 자리를 차지해 “삼성전자 0…”이 됩니다. 출처 링크가 머리 영역에 있고, 주기 칩은 5분부터 시작해 선택된 ‘일’이 가운데로 밀립니다.

메뉴차트 우클릭에 차트 동작이 없음

첫 줄이 비활성 ‘붙여넣기’이고 나머지는 드로잉 일괄 동작뿐입니다. 관심종목 넣기, 가격선, 축 초기화처럼 차트 위에서 자주 하는 일이 빠져 있고 단축키도 안 보입니다.

메뉴단축키 도움말: 18줄을 한 줄로 나열

270px 폭에 마우스·키 조합이 묶음 없이 늘어서 차트 왼쪽을 다 덮습니다. 키 칸이 들쭉날쭉해서 빨리 훑어보기 어렵습니다.
