H. 규칙
모든 겹쳐 뜨는 화면의 공통 규칙
· 화면 맨 위 층에 그려서 다른 영역에 잘리지 않음
· 화면 가장자리에 닿으면 반대쪽으로 열림
· Esc나 바깥 클릭으로 닫히고, 연 버튼으로 포커스가 돌아감
· ↑↓·↵·글자 입력으로 항목 이동
· 같은 표면색·테두리·반경 10·그림자
· 브라우저 기본 select는 쓰지 않음
  • 1A. 봉 모양 메뉴: 지금은 도구 막대 영역에 잘려 "캔들" 한 줄만 보입니다. 공통 팝오버로 옮기면서 아이콘과 단축키를 붙입니다.
  • 2B. 분봉 선택: 브라우저 기본 select를 칩 격자로 바꿉니다. 별표한 분봉은 위 막대에 고정합니다.
  • 3C·D. 관심종목 메뉴: 목록 전환·관리와 행 동작을 나누고, 지우는 동작은 빨간색으로 맨 아래에 둡니다.
  • 4E. 자석 세기: 왼쪽 막대의 "약 ▾" select를 없애고, 자석 버튼 우클릭이나 길게 누르기로 고릅니다. 고를 때 설명이 함께 보입니다.
  • 5F. 색상 선택: 16색 팔레트, 최근 쓴 색, hex 입력, 투명도를 한 팝오버에 넣습니다.
  • 6G. 툴팁에 단축키 표시. 되돌릴 수 있는 동작은 알림에 [되돌리기]를 두고, 되돌릴 수 없는 동작만 확인 창을 띄웁니다.
