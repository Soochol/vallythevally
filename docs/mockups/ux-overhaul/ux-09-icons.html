  • 1A·B는 지금 코드의 그림 정보를 그대로 그렸습니다. 공통 아이콘은 1.5px 선, 24×24, currentColor로 그립니다.
  • 2B의 ToolIcon을 공통 Icon으로 합칩니다. 크기 22→18, 그림 정보는 icons.tsx 한 곳에서 관리합니다. 추세선·수평선의 아이콘 값(toolSpec의 icon 문자열)은 그대로 씁니다.
  • 3C의 범례 버튼은 React 밖에서 DOM으로 만듭니다. 그래서 icons.tsx에서 그림 정보를 문자열로도 꺼내 쓸 수 있게 하고, legendRows·compareLegend가 그것을 씁니다.
  • 4D는 1~7번 시안에 실제로 나오는 것만 추가합니다. 각 아이콘을 쓰는 티켓에서 함께 넣습니다.
  • 5드로잉 도구는 지금 추세선·수평선 두 개만 구현되어 있습니다. 시안 ⑥의 그룹(피보나치·도형 등)은 도구가 생길 때 보이게 하고, 이번 개편에서는 새 도구를 만들지 않습니다.
