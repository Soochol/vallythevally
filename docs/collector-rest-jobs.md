# 수집기 REST 작업 표 (초안)

수집기가 키움 REST로 모으는 작업의 목록이다. 결정은 [ADR 0025](adr/0025-collector-stores-closed-days-for-the-app.md)와 [ADR 0026](adr/0026-collector-supervisor-collects-common-and-preferred-stocks.md)에 있다. 대상은 보통주와 우선주(스팩 포함)라 ETF마다 부르는 TR은 없다. 요청 인수는 키움 공식 명세(`kiwoom_api_spec.json`, 2026-08-03에 hoga-ops가 받은 337개 API 파일)에서 옮겼다. 이 표의 TR은 아직 하나도 실제로 불러 보지 않았다.

순위, 종목 단면, 기준 정보, 차트 이력은 앱이 맡으므로 여기 없다. WebSocket이 같은 내용을 주는 TR(체결·호가·거래원·종목 프로그램·업종 지수의 당일 흐름)도 없다.

## 열의 뜻

- **때**: `장중`은 장중에 주기적으로, `마감 뒤`는 20:05에 WebSocket을 끈 뒤 하루 한 번이다.
- **범위**: 한 번 부를 때 무엇 하나를 받는지다. `시장`은 시장 구분 하나, `업종`은 업종 코드 하나, `종목`은 종목 하나다.
- **변형**: 같은 범위에서 인수만 바꿔 여러 번 불러야 하는 것이다. 몇 가지를 부를지는 아직 정하지 않았다.
- 모든 TR이 연속조회(`cont-yn`·`next-key`)를 받는다. 한 범위에 몇 쪽이 오는지는 실측한다.

## 수집 계획에 쓰는 조회

저장하려고 부르지 않는다. 07:20에 감독 데몬이 예비 키로 불러 그날 수집 계획의 입력으로 쓴다. 마감 뒤에 한 번 더 불러 아침 목록과의 차이만 남긴다.

| TR | 이름 | 쓰는 곳 |
|---|---|---|
| `ka10099` | 종목정보 리스트 | 수집 종목 목록(`universe/<날짜>`) |

## 하루 호출 어림

종목마다 부르는 마감 뒤 TR은 12개다(`ka10008`·`ka10045`·`ka10059`·`ka10060`·`ka10061`·`ka10013`·`ka10014`·`ka20068`·`ka10015`·`ka10047`·`ka10087`·`ka90013`). 약 2,600종목에 변형 하나, 한 쪽씩이면 약 31,000회다. 유량은 (키, TR)마다 초당 5회이고 서로 독립이다(hoga-ops ADR-0138 실측). 수집 키 14개로 나누면 TR 하나에 약 40초다. TR을 하나씩 차례로 돌리면 약 8분이 걸린다. 키 하나에 모든 TR을 합친 한도가 따로 있는지는 아직 재지 않았다.
