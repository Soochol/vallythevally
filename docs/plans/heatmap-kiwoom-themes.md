# 히트맵 키움 테마 탭 플랜

작성일 2026-11-22. 기준: `origin/main` 9d02db52. 제안(합성 자료 화면 예시와 실측 결과): https://claude.ai/artifact/Xeda2yLqGZ87j3QpBE4yM2

## 사용자가 정한 것

- 히트맵의 그룹·종목을 키움이 정한 분류로도 보고 싶다. 내 테마([히트맵 테마 플랜](heatmap-themes.md))는 그대로 두고 **탭으로 추가**한다.
- 종목이 1~2개인 작은 테마도 **일단 모두 보인다**.

## 실측(2026-11-22, 실서버 `/api/kiwoom-themes`)

- 키움 테마 142개, `ka90001` 2쪽. 코드는 3자리 숫자.
- 테마당 종목 최소 1 · 중앙값 5 · 최대 26, 소속 합 895. `ka90002`는 테마당 1쪽.
- 기간 인수 두 자리가 된다. 구성종목에 거래대금 칸이 없다. 응답 모양은 가이드와 같다.

## 결정

1. **구성종목은 하루 한 번 받아 저장한다.** 서버가 `ka90001`(1일)로 테마 목록을, 테마마다 `ka90002`로 구성종목 코드를 받아 `<사용자 DB 폴더>/kiwoom-themes/YYYYMMDD.json`에 둔다. 폴더는 `VALLY_KIWOOM_THEMES_DIR`로 바꾼다.
   - 배경 우선순위(`Priority::Background`)로 보내고, 키움이 연결돼 있을 때만 받는다.
   - 매일 08:30(KST) 이후 첫 기회에 받는다. 서버가 켜질 때 오늘 파일이 없고 08:30이 지났으면 바로 받는다. 오늘 파일이 있으면 다시 받지 않는다.
   - 한 테마의 구성종목을 받지 못하면 가장 최근 파일의 그 테마 구성종목을 쓰고, 그것도 없으면 그 테마를 뺀다. 테마 목록 자체를 받지 못하면 가장 최근 파일을 그대로 쓴다.
   - 비용은 하루 144건쯤이다(목록 2 + 테마 142).
2. **보드는 출처만 바뀐다.** `GET /api/heatmap/board`에 `source=mine|kiwoom`(기본 `mine`)을 더한다. `kiwoom`이면 저장된 구성종목으로 테마를 만들고, 시세·요약·순서는 내 테마와 같은 코드(`ka10095`, 거래대금 가중 평균)로 계산한다. 겹침을 빼면 종목은 895개 이하라 시세는 `ka10095` 9건 이하다.
3. **화면은 두 단계다.** 키움 테마 탭은 1단계로 테마 지도(칸 하나가 테마, 크기는 거래대금 합, 색은 가중 평균 등락률)를 보이고, 테마를 고르면 2단계로 그 테마의 칸 지도(내 테마 카드와 같은 부품)를 보인다.
4. **키움 테마 탭에서는 편집하지 않는다.** 대신 고른 테마에 "내 테마로 가져오기"를 둔다. 같은 이름의 내 테마가 있으면 가져오지 않고 알린다.
5. **흐름 비교는 키움 테마 탭에서 고른 테마 하나만 그린다.** 테마 142개를 모두 그리면 분봉 호출이 수백 건이라서다.

## 서버 응답 계약

`HeatmapBoard`에 두 칸을 더한다.

```jsonc
{
  "revision": 0,
  "order": "rate",
  "asOf": 1795000000,
  "source": "kiwoom",               // "mine" | "kiwoom"
  "catalog": {                       // source가 kiwoom일 때만, 아니면 null
    "date": "2026-11-23",           // 구성종목을 받은 날. 받은 적이 없으면 null
    "collectedAt": 1794999000,       // 받은 시각. 없으면 null
    "themes": 142,                   // 저장된 테마 수
    "state": "ready"                 // "ready" | "collecting" | "empty"
  },
  "themes": [
    { "id": "kiwoom-319", "name": "조선", "summary": { … }, "members": [ … ], "missing": [ … ] }
  ]
}
```

- 키움 테마의 `id`는 `kiwoom-<테마코드>`다.
- `state`: 저장된 파일이 있으면 `ready`(오늘 것이 아니어도), 없고 받는 중이면 `collecting`, 없고 받고 있지도 않으면 `empty`.
- 내 테마(`source=mine`)의 응답은 `source: "mine"`, `catalog: null`만 더해지고 나머지는 지금과 같다.

웹 주소는 `/heatmap?source=kiwoom&theme=kiwoom-319`다. `source`가 없으면 내 테마다.
