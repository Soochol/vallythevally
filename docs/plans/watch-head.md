# 관심종목 머리의 더하기 버튼 정리 플랜

작성일 2026-11-17. 승인 시점의 기록이며 구현 중 바뀐 것은 반영하지 않는다.

기준: `origin/main` d71d124.

## 사용자가 풀려는 문제

사용자의 말(그대로):

> 관심종목 상단에 그룹+ , +  햇갈리지 않아? uiux 제안

캡처에는 관심종목 창 머리의 "기본 ⌄ 8종목 … + 그룹  +"와 바로 위 도킹 탭 줄 끝의 "+"가 함께 보인다. 사용자는 구현 전에 시각 미리보기를 보고 안을 고르기로 했다.

## 미리보기

"지금 vs 안 A·B·C" 미리보기를 만들었다. 지금 화면은 이 기준 커밋을 격리된 샌드박스(verify-vally)로 띄우고 그룹 셋과 그룹 없는 종목 하나를 넣은 뒤 1440×860 창과 390×844 휴대폰 창에서 찍은 캡처다. 안 A·B·C는 제품의 색 토큰과 치수로 그렸고, 목록 메뉴·분할 메뉴·새 그룹 칸을 눌러 볼 수 있으며 B에서는 종목 줄을 새 그룹 칸으로 끌어 볼 수 있다. 미리보기 파일은 저장소에 넣지 않는다. 아래 그림은 그 내용을 글자로 옮긴 것이다.

```
지금     [관심종목○][스크리너○][개체 목록]                  +   ← 이 묶음에 창 더하기
         기본⌄ 8종목                          + 그룹    +       ← 새 그룹 / 관심종목에 넣기

안 A     기본⌄ 8종목                      ⊞ 새 그룹 [+ 종목]
안 B     기본⌄ 8종목                                [+ 종목]     (권장)
         …목록…
         ┌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐
         ╎ + 새 그룹          종목을 끌어 놓아도 됩니다 ╎   ← 목록 맨 아래 칸
         └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘
안 C     기본⌄ 8종목                            [+ 종목 │⌄]   ← ⌄: 새 그룹 · 새 목록

휴대폰(안 B)  기본⌄ 8종목            [+ 종목] ●재무자료 편집
```

안 B의 목록 메뉴(기본 ⌄): 목록 / ✓ 기본 8 / ─ / **새 그룹** / 새 목록 / 이름 바꾸기 / 복제 / ─ / 열 … / ─ / 목록 지우기.

## 확인한 사실

### 관심종목 머리

- 머리는 `web/src/features/watch/Watchlist.tsx`의 `WatchHead` 하나가 데스크톱(`WatchPanel`)과 휴대폰(`PhoneWatch`)에 그린다. 순서는 목록 메뉴 버튼(`ListMenu`, 접근성 이름 "관심종목 목록: 기본"), 종목 수, (연결 전이면 "저장된 목록 · 시세 없음"), 빈 칸, 새 그룹 버튼, 종목 넣기 버튼이다. 휴대폰은 뒤에 재무자료 버튼과 편집 버튼이 붙는다.
- 새 그룹 버튼은 `tb-btn` 높이 28px에 12px 더하기 아이콘과 "그룹" 글자이고 접근성 이름은 "새 그룹"이다. 누르면 `startGroup`이 맨 끝에 "그룹 N"을 만들고 그 그룹 머리에 이름 칸을 연다. 그룹이 100개(`MAX_WATCH_GROUPS`)면 비활성이다.
- 종목 넣기 버튼은 글자 없는 32px `icon-btn`의 16px 더하기다. 접근성 이름은 "관심종목에 넣기", `title`은 "기본에 넣기"이고, `openSearch("watch")`로 "관심종목에 넣을 종목 검색" 대화상자를 연다.
- 목록 메뉴는 이미 목록 단위 메뉴다. 목록 고르기(라디오), 새 목록·이름 바꾸기·복제, 열 고르기(체크), 목록 지우기가 있다.
- 종목 줄 메뉴에 "그룹으로 옮기기 › 새 그룹…"(`moveToNewGroup`)과 "그룹에 추가 › 새 그룹…"(`startGroup`에 그 종목)이 있다. 다른 그룹으로 끌어 놓기는 지난 플랜(`ui-polish.md`)에서 들어왔다. 머리·줄 위에 놓으면 옮기고 Ctrl(맥 Option)로 복사하며, 그룹 없음에서 끈 줄은 옮긴다.
- 빈 목록 안내는 "{목록 이름}에 종목이 없습니다. +로 종목을 넣으세요"와 "종목 넣기" 버튼이다.

### 위쪽 탭 줄

- 도킹 탭 줄 끝의 "+"는 `web/src/features/workspace/AddWindowMenu.tsx`의 `.dock-add`(26px, `--text-3`)이고 접근성 이름은 "이 묶음에 창 더하기"다. 창 종류 메뉴를 연다.

### 스크리너 머리

- 데스크톱 스크리너 머리(`web/src/features/screener/SentenceEditor.tsx`)는 조건식 이름 ⌄(고르기), 저장, ⋯(이름 바꾸기·새 조건식·복제·지우기)이다. 글자 없는 더하기가 없다.
- 휴대폰 스크리너 머리(`web/src/features/screener/ScreenerPanel.tsx`의 `ScreenHeader`)는 조건식 이름 ⌄, 편집, 글자 없는 더하기(접근성 이름 "새 조건식"), ⋯(스크리너 메뉴)이다. 조건식 고르기 메뉴(`ScreenPicker`) 끝에 같은 동작 "새 조건식…"이 이미 있다.
- 조건식이 하나도 없을 때 결과 자리의 안내(`NoScreen`)에는 "새 조건식" 버튼이 있다. 데스크톱 E2E 여럿이 이 버튼을 누른다.

### 시험과 검증 스킬이 쓰는 이름

- "관심종목에 넣기" 버튼: `web/e2e/watchlists.spec.ts`, `web/e2e/search.spec.ts`, `.claude/skills/verify-vally/scripts/drive.mjs`의 `watchlist-add` 여정.
- "새 그룹" 버튼: `web/e2e/watchlist-groups.spec.ts`, `web/e2e/win-journey.spec.ts`(떠 있는 관심종목 창).
- 휴대폰 "새 조건식" 버튼: `web/e2e/screener-phone.spec.ts`.
- 직전 ui-polish 작업들은 바뀐 이름을 쓰는 E2E를 다 돌리지 않아 병합 뒤 실패가 났다. 이번 지시서는 `git grep`으로 찾은 E2E를 모두 돌리게 적었다.

## 스스로 정한 결정

| 결정 | 이유 |
|---|---|
| 안 B의 새 그룹 메뉴는 새 ⋯ 버튼을 만들지 않고 기존 목록 메뉴(기본 ⌄)에 "새 그룹"을 새 목록 위에 더한다. | 그 메뉴가 이미 목록 단위 동작(새 목록·이름 바꾸기·복제·열·지우기)을 모은 메뉴다. ⋯를 더하면 같은 성격의 메뉴가 둘이 된다. "새 그룹"과 "새 목록"이 나란히 있어 둘의 차이도 드러난다. |
| [+ 종목]의 접근성 이름은 "관심종목에 넣기" 그대로, `title`은 "{목록 이름}에 넣기 (종목 검색)"이다. | 보이는 글자 "종목"이 접근성 이름 안에 든다. 이 이름으로 찾는 E2E와 verify-vally 여정이 그대로 쓴다. |
| [+ 종목]은 높이 28px(휴대폰 36px), 1px `--line-strong` 안쪽 테두리, 강조색 더하기 아이콘, 12px 굵기 600 `--text` 글자다. 포인터를 올리면 `--hover` 바탕에 테두리가 `--accent`다. | 실행 버튼(`btn-primary`)과 무게가 겹치지 않게 했다. 채움으로 할지는 결정 4로 묻는다. |
| 목록 맨 아래 "+ 새 그룹" 칸은 버튼이고 접근성 이름은 "새 그룹"이다. 높이 34px, 좌우 10px 띄움, 1px `--line-strong` 점선 테두리, `--text-2` 글자다. 데스크톱은 오른쪽에 `--text-3` 11px "종목을 끌어 놓아도 됩니다"를 보인다. | 지금 머리 버튼의 이름을 이어받아 그 이름으로 찾는 시험이 위치만 바뀐다. 그룹 머리와 같은 높이라 목록의 한 줄로 읽힌다. |
| 칸을 누르면 지금 머리 버튼과 같다(`startGroup`, 맨 끝 "그룹 N", 이름 칸). | 동작을 새로 만들지 않는다. |
| 데스크톱에서 종목 줄을 칸에 놓으면 그 종목으로 새 그룹을 만들어 옮긴다(`moveToNewGroup`). Ctrl(맥 Option)을 누른 채 놓으면 복사한다(`startGroup`에 그 종목). 그룹 없음에서 끈 줄은 키와 상관없이 옮긴다. 놓은 뒤 새 그룹 머리에 이름 칸을 연다. | 종목 줄 메뉴의 "그룹으로 옮기기 › 새 그룹…", "그룹에 추가 › 새 그룹…"과 같은 결과이고, 그룹 간 끌기의 복사 규칙과 같다. |
| 끄는 동안 칸 위에서는 `--accent-soft` 바탕, 1px `--accent` 테두리, "여기 놓으면 새 그룹으로 옮김"(복사면 "…복사")을 보인다. | 그룹 머리에 놓을 때의 표시와 같은 색 규칙이다. |
| 목록이 비면 칸을 숨긴다. 그룹이 100개면 칸은 비활성이고 `title`과 글자로 "그룹은 100개까지입니다"를 보인다. | 빈 목록에서는 안내의 "종목 넣기"가 먼저다. 한도는 지금 버튼과 같다. |
| 휴대폰은 칸을 누르기만 한다(끌기 없음). | 지금도 휴대폰에는 끌기가 없다. |
| 빈 목록 안내 제목은 "{목록 이름}에 종목이 없습니다"로 줄인다. | "+로"가 가리키던 버튼에 이제 글자가 있고, 안내에 "종목 넣기" 버튼이 함께 있다. |
| 도킹 탭 줄 끝의 "+"는 바꾸지 않는다. | 안 B가 되면 글자 없는 더하기는 이것 하나만 남아 "창 더하기"로 읽힌다. |

## 작업과 순서

| 작업 ID | 내용 | 방식 | 방식의 이유 | 시작 조건 |
|---|---|---|---|---|
| `watch-head` | 관심종목 머리를 [+ 종목] 하나로 줄이고, 새 그룹을 목록 메뉴와 목록 맨 아래 칸으로 옮기며, 칸에 끌어 놓아 새 그룹을 만든다 | `poteto` | 저장되는 관심종목 자료를 바꾸는 새 끌어 놓기 대상을 기존 끌기 상태에 더한다 | 바로 시작 |
| `screener-phone-plus` | 휴대폰 스크리너 머리의 "새 조건식" 더하기를 뺀다 | `basic` (`minor-fix`) | 버튼 하나와 시험 한두 곳 | 바로 시작 |

```
watch-head
screener-phone-plus
```

병렬로 둔 이유:

- 두 작업은 소스 파일이 겹치지 않는다(`Watchlist.tsx`와 `ScreenerPanel.tsx`).
- `docs/design-system.md`는 `watch-head`만 관심종목 창 머리 문단을 고친다. 그 문서에는 휴대폰 스크리너 머리의 버튼을 적은 곳이 없어 `screener-phone-plus`는 고치지 않는다.
- 지금 진행 중인 `float-content-fix`는 `web/src/styles/ui.css`의 위 막대 규칙과 `float-content`, `system-settings`, `win-shell`, `list-format` E2E를 고친다. 두 작업은 이 파일들을 고치지 않는다(`ui.css`는 고칠 일이 없다). 순서를 둘 필요가 없다. 지시서에 그 파일들을 건드리지 말라고 적었다.

결정 1에서 A나 C를 고르면 `watch-head` 지시서의 머리 부분만 바꾼다. 결정 3에서 "그대로"를 고르면 `screener-phone-plus`를 뺀다.

## 범위 밖

- 도킹 탭 줄의 창 더하기, 위 막대의 창 더하기.
- 데스크톱 스크리너 머리(이미 ⋯ 메뉴 꼴이다), 조건식이 없을 때의 "새 조건식" 안내 버튼.
- 그룹 머리·종목 줄의 모양(지난 플랜에서 정했다), 그룹 머리를 끌어 그룹 순서 바꾸기, 다른 목록으로 끌기, 휴대폰 끌기.
- 목록 메뉴를 고르기와 동작 메뉴로 나누는 일.

## 사용자가 정해야 하는 결정

미리보기에 권장안과 다른 선택지를 함께 보였다. 정하지 않으면 권장안으로 진행하고, 다르게 정하면 맡는 작업의 지시서만 고친다.

| # | 물음 | 권장(지시서에 적용) | 다른 선택지 | 맡는 작업 |
|---|---|---|---|---|
| 1 | 머리의 두 더하기 | 안 B: 머리에는 [+ 종목] 하나, 새 그룹은 목록 메뉴와 목록 맨 아래 칸 | 안 A: [⊞ 새 그룹]과 [+ 종목] 두 버튼 / 안 C: [+ 종목 ⌄] 분할 버튼(⌄에 새 그룹·새 목록) | `watch-head` |
| 2 | 목록 맨 아래 "+ 새 그룹" 칸(끌어 놓으면 그 종목으로 새 그룹) | 넣는다 | 목록 메뉴에만 둔다 | `watch-head` |
| 3 | 휴대폰 스크리너 머리의 "새 조건식" 더하기 | 뺀다(조건식 고르기 메뉴의 "새 조건식…"으로) | 그대로 둔다 | `screener-phone-plus` |
| 4 | [+ 종목] 모양 | 1px 옅은 테두리, 더하기 아이콘만 강조색 | 강조색 채움 | `watch-head` |
