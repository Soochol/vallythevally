# 스크리너 창의 조건 요약 줄 없애기

작성일: 2026-11-18. 승인 시점의 기록이며 구현 중 바뀐 것은 반영하지 않는다.

## 사용자가 풀려는 문제

스크리너 창 머리에 조건식을 사람말로 풀어 쓴 줄과 대상 범위 줄이 보인다.

```
주봉 최근 260주 이내 거래량이 260주 신고거래량인 봉이 있다
시가총액이 3,000억 원 이상이다
전 종목 대상 · ETF·우선주·리츠·스팩 제외
```

사용자는 스크리너에서 이 줄들을 없애 달라고 했다. 빠르게 끝내길 원한다.

## 코드에서 찾은 것

- 데스크톱 스크리너 창은 `web/src/features/screener/SentenceEditor.tsx`의 `aria-label="조건 요약"` 블록이 이 줄들을 그린다. 조건 문장 최대 3줄(`SUMMARY_LINES`), "외 N개 조건", 조건이 없을 때 `NO_CONDITIONS_SENTENCE`, `scopeSummary`가 만든 대상·제외 한 줄이다. 붙여 넣은 문구의 "전 종목 대상 · … 제외" 모양은 `scopeSummary`의 출력과 같다.
- 휴대폰 폭에서는 `web/src/features/screener/ScreenerPanel.tsx`의 `ScreenHeader`가 `ScreenSummary`로 같은 내용(대상·제외 칩과 조건 목록)을 그린다.
- 조건식을 편집하는 곳(데스크톱 `조건 편집 창`의 `SentenceFields`, 휴대폰 `ScreenDialog`)은 조건을 고르고 고치는 데 문장이 필요하다.
- `docs/design-system.md`가 `SentenceEditor`의 조건 요약을 설명한다.
- 단위 시험 `ScreenerPanel.test.ts`와 e2e `screener-editor-window.spec.ts`, `screener-no-conditions.spec.ts`가 패널의 조건 요약 문구로 상태를 확인한다.

## 확정된 결정

- 스크리너 창 머리의 조건 문장 줄과 대상·제외 줄을 없앤다.
- 미리보기는 만들지 않는다. 문구를 지우는 일뿐이다.

## 스스로 정한 결정과 이유

- **휴대폰 폭의 `ScreenSummary`도 없앤다.** 사용자는 "스크리너에서" 없애 달라고 했고, 휴대폰 머리의 요약은 같은 정보를 다른 모양으로 보인다. 한쪽만 남기면 화면 폭에 따라 다르게 보인다.
- **편집 화면의 문구는 남긴다.** `조건 편집 창`의 `SentenceFields`, 휴대폰 `ScreenDialog`의 조건 문장과 `NO_CONDITIONS_SENTENCE`는 조건을 고르고 고치는 데 필요하다. 사용자가 붙여 넣은 것은 스크리너 창 머리의 줄이다.
- **조건식이 잘못됐을 때의 `FIX_INVALID` 줄은 남긴다.** 라벨이 아니라 오류 안내이고, 편집 창을 닫았을 때 실행이 왜 안 되는지 알려 주는 유일한 줄이다.
- **시험은 요약 대신 편집 창이나 저장된 문서로 같은 상태를 확인한다.** 요약 문구를 보던 단언은 "요약이 없다"는 단언과, 같은 값을 편집 창이나 저장된 조건식에서 보는 단언으로 바꾼다. 확인하던 상태(대상·제외·조건 저장 결과)는 그대로 확인하므로 검증이 약해지지 않는다.

## 작업

| 작업 | 방식 | 이유 |
|---|---|---|
| `screener-labels` (minor-fix) | basic | 화면 문구 제거와 그에 맞춘 시험·문서 수정이다. 상태 저장·동시성·새 설계가 없다. |

작업은 하나다. 같은 시각에 `mw-screener`(창별 조건식)가 `web/src/features/screener/`와 `screener-editor-window.spec.ts`를 고칠 수 있다. 이 작업은 블록을 지우는 몇 줄 변경이라 병렬로 두고, 지시서에 최소 변경을 적는다.

## 범위 밖

- 조건 문장 생성(`conditionSentence`)과 `web/src/lib/screener.ts`의 문구.
- 편집 창·휴대폰 편집 대화상자의 문구.
- 결과 표, 실행 버튼 줄의 안내 문구(`저장 전에도 실행할 수 있습니다` 등).

## 사용자가 정해야 하는 결정

- 휴대폰 폭의 요약도 없애는 것을 기본으로 했다. 휴대폰에서는 남기길 원하면 알려 주면 된다.
