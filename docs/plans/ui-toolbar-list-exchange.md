## 미리보기

네 항목을 가상 종목·가상 시세로 눌러 볼 수 있는 미리보기를 만들어 사용자에게 전달했다. 사용자는 미리보기를 보고 5번을 더했고 나머지는 권장안으로 정했다. 5번도 같은 미리보기에 넣어 다시 전달했다. 미리보기 파일은 저장소에 넣지 않았다. 아래 그림은 그 내용을 글자로 옮긴 것이다. 미리보기는 제품 화면이 아니며, 실제 화면에서의 확인은 각 작업의 E2E가 맡는다.

### 1. 드로잉 도구 막대

```
평소(접힘)                                마우스를 올림(펼침)
┌───────────── 활성 칸 ─────────────┐      ┌───────────── 활성 칸 ─────────────┐
│ 가상전자 3분        (／)           │      │ 가상전자 3분 (⠿ ↖ ／ ≡ □ T ⌖ ⌇ │ ⌫ ∪ ✎ │ ☰ ?) │
│ 71,900 ▲700 +0.98%                │      │ 71,900 ▲700 +0.98%   범례는 그대로 │
│ 시 고 저 종 량                     │      │ 시 고 저 종 량                     │
```

접힌 알약에는 지금 고른 도구의 아이콘 하나만 보인다. 펼친 막대는 접힌 알약의 자리에서 양옆으로 넓어지고 범례 위에 겹쳐 뜬다.

```
연속 그리기 켬 ──▶ 막대가 펼친 채로 남는다(마우스가 벗어나도)
                    │ 차트에서 우클릭 또는 Esc
                    ▼
연속 그리기 꺼짐, 선택 도구로 돌아감, 막대 접힘(이 우클릭은 차트 메뉴를 열지 않는다)
```

```
(이름 14px, 배지)      (전체 12px, 색 글자)    (두 목록이 같은 글자 크기·굵기·줄 높이·배지, 이름만)
```

## 확인한 사실

### 1. 드로잉 도구 막대

- 대상은 용어집의 **드로잉 도구 막대**다(`web/src/features/drawings/DrawingToolbar.tsx`, `.drawing-toolbar`). 활성 칸 위쪽 가운데에 뜨고, 손잡이로 옮긴 자리는 `UiPrefs.drawing.dockAt`(막대 가운데의 가로 비율, 위 가장자리의 세로 비율)에 저장한다. 휴대폰 폭에는 없다.
- 막대의 자리와 폭은 `useDockPlacement`가 정하고, 그 결과를 `data-dock-normal`로 범례에 알린다. 범례(`web/src/chart/legend.ts`의 `refreshPresentation`)는 막대와 글자가 만나면 범례를 막대 높이만큼 내리거나(`--legend-shift`), 가격 패널에 들어가지 않으면 작은 글자로 바꾸고 막대를 범례 옆에 둔다(`data-legend-beside`).
- `docs/design-system.md`는 "같은 자료와 창 크기에서는 십자선을 움직여 표시값이 바뀌어도 범례 밀도와 도구 막대 자리가 바뀌지 않는다"고 정한다.
- 도구를 누르면 초점이 차트로 돌아간다(`surfaceFor(cellId)?.focus()`).
- **연속 그리기**는 두 가지로 켠다. 막대의 연속 그리기 버튼은 앱 전체 설정 `UiPrefs.drawing.keepDrawing`을 바꾸고 새로고침 뒤에도 남는다. 도구를 두 번 누르면 그 도구만 연속이 되고(`useDrawingSession`의 `pinnedTool`) 저장하지 않는다. 둘 중 하나가 켜져 있으면 다 그린 뒤에도 도구가 남는다(`web/src/chart/drawings/DrawingSurface.ts`).
- Esc는 그리던 것을 취소하거나 마치고 도구와 선택을 푼다. `keepDrawing`은 바꾸지 않는다. 차트에서 우클릭하면 그리던 것을 취소하고 차트 메뉴(`drawingMenu`)를 연다. 연속 그리기는 그대로 남는다.
- 막대의 버튼을 누르는 E2E가 20개 파일에 있다(`web/e2e/drawing-*.spec.ts`, `float-dock.spec.ts`, `chart-readability.spec.ts`, `win-*.spec.ts` 등). 막대를 찾는 공용 도우미는 `web/e2e/drawing-probe.ts`에 있다.

### 2. 두 목록의 서식

| 항목 | 관심종목(`web/src/features/watch/Watchlist.tsx`) | 스크리너 결과(`web/src/features/screener/ResultTable.tsx`) |
|---|---|---|
| 마크업 | `ul`·`li`·줄 전체가 버튼인 격자 | `table`, 이름 칸 안에 버튼 |
| 종목 칸 | 이름 14px 굵기 550, 남는 폭에만 코드 11px(지수는 "지수") | 이름 12px 굵기 600, 코드 11px |
| 현재가 | 14px | 12px, 잠정이면 `*`, 옛 일봉이면 아래에 날짜 |
| 등락률 | 12px 굵기 550의 색 배지 | 12px 굵기 600의 색 글자 |
| 줄 | 34px, 줄 사이 선 없음 | 34px, 옅은 줄 사이 선 |
| 고른 줄 | 왼쪽 강조색 선, `surface` 바탕 | 왼쪽 강조색 선, `accent-soft` 바탕 |
| 열 머리 | 11px, 선 없음 | 11px, 위아래 선, 누르면 정렬 |
| 열 폭 | 현재가 76px, 등락률 60px(열은 사용자가 고름) | 현재가 80px, 등락률 64px(고정) |

휴대폰 폭의 관심종목은 줄 높이 56px의 다른 배치를 쓴다.

### 3. 줄 메뉴

- 관심종목 줄(데스크톱)은 우클릭, `Shift+F10`, 메뉴 키로 메뉴를 연다. 항목은 이 칸에 열기, 비교에 추가, 맨 위로, 그룹에 추가, 그룹으로 옮기기, 다른 목록에 복사, 이 그룹에서 빼기, 관심종목에서 빼기다. 둘째 메뉴(그룹·다른 목록)는 같은 자리에서 메뉴를 바꿔 보인다.
- 스크리너 결과 줄에는 메뉴가 없다. 줄을 누르거나 ↑↓로 칸에 연다(`openResult`). 결과 전체를 관심종목으로 보내는 메뉴(`PanelMenu`)가 따로 있고, 한 종목을 보내는 조작은 없다.
- 공용 `Menu`(`web/src/features/menu/Menu.tsx`)는 누른 자리에 뜨고 화면 밖으로 나가지 않으며 화살표·글자·Esc를 처리한다.

### 4. 거래소

- 거래소는 칸마다 고른다(ADR 0007). 값은 레이아웃의 차트 창마다 저장한다(`LayoutWindow.venue`, 서버 `layout_windows.venue`). 고르는 곳은 범례 머리줄(범례를 끄면 봉 값 줄 앞)과 휴대폰 머리다(`web/src/features/venue/VenuePicker.tsx`).
- 칸의 봉, 실시간 현재 봉, 세부 봉, 비교 종목, 차트 이미지의 머리와 파일 이름이 칸의 거래소를 따른다.
- 칸의 거래소를 따르지 않는 곳은 다음과 같다.

| 곳 | 지금 쓰는 거래소 | 근거 |
|---|---|---|
| 관심종목 시세(조회) | 통합 | `crates/server/src/quotes.rs`의 `StockQuotes::new(chunk, Venue::Combined)` |
| 관심종목 시세(실시간) | 통합 | `crates/server/src/market/hub.rs`의 `publish_quote`. 통합 흐름의 가격·전일대비·누적 거래량을 그대로 쓴다 |
| 종목 검색의 시세와 작은 차트 | 통합 | `web/src/features/search/useSearchQuotes.ts`, `SearchPreview.tsx` |
| 스크리너 | KRX | 저장소가 KRX 일봉뿐이다(ADR 0010, 0014) |
| 종목 기본 정보 | 통합 | ka10001 |

- 키움의 여러 종목 현재가(ka10095)는 종목코드 접미사로 거래소를 고른다. 서버의 `StockQuotes::new`는 이미 거래소를 받는다(스크리너가 KRX로 쓴다).
- 실시간은 통합 흐름 하나(`_AL`)에서 체결마다 거래소(`9081`)를 읽어 칸의 키로 나눈다(`hub.rs`의 `accepts`). 체결에 실려 오는 당일 누적 거래량은 통합 값이다.
- NXT에서 거래되지 않는 종목(`nxtEnabled=false`, 주식의 약 78%)은 NXT를 고를 수 없다. 지수에는 거래소가 없다.
- 앱 전체 설정(`UiPrefs`, `web/src/persist/uiState.ts`)은 서버가 해석하지 않고 그대로 저장한다.
- 서버는 레이아웃을 저장할 때 차트 창의 거래소가 NXT이면 그 종목이 NXT에서 거래되는지 확인한다(`crates/server/src/user_routes.rs`). DB는 주식 창에 거래소가 있고 지수 창에 없을 것을 요구한다.

## 확정된 결정 (사용자의 말)

- 드로잉 도구 막대는 평소에 접혀 있고, 마우스를 올리면 펼쳐지며, 벗어나면 줄어든다.
- 관심종목 목록과 스크리너 목록의 서식을 맞춘다. 글자를 맞추고, 종목 이름만 쓰고 종목코드는 쓰지 않는다.
- 스크리너 결과에서 종목을 우클릭하면 그 자리에 맞는 메뉴가 나온다.
- 거래소를 차트에서 빼서 위 막대 쪽에 두고 앱 전체에 하나만 고른다. 바꾸면 모든 화면이 그 거래소로 바뀐다.
- 네 항목 모두 미리보기를 먼저 보고 진행한다.
- 연속 그리기가 켜져 있으면 드로잉 도구 막대는 접히지 않고 펼친 채로 남는다. 우클릭하거나 Esc를 누르면 연속 그리기가 풀리면서 막대가 접힌다.
- 나머지는 권장안으로 한다. 아래 "사용자가 정한 결정"의 표에 적었다.

## 스스로 정한 결정과 이유

### 1. 드로잉 도구 막대 접기

| 결정 | 이유 |
|---|---|
| 접힌 막대는 지금 고른 도구(선택 도구, 드로잉 도구, 지우개 같은 모드)의 아이콘 하나를 담은 알약이다. 도구나 모드를 고른 상태면 강조색이다. | 접혀 있어도 지금 무엇으로 그리는지 보인다. 단축키로 도구를 바꿔도 알 수 있다. |
| 마우스나 펜이 막대 위에 80ms 머물면 펼친다. 막대 안에 키보드 초점이 들어와도, 터치로 알약을 눌러도 펼친다. | 지나가는 포인터에는 반응하지 않는다. 키보드와 터치에도 길이 있어야 한다. |
| 포인터가 벗어나고 0.4초 뒤에 접는다. 초점이 막대 밖으로 나가거나 바깥을 터치해도 접는다. | 버튼 사이를 옮기다 잠깐 벗어나도 닫히지 않는다. |
| 도구 묶음 메뉴, 자석 세기 메뉴, 단축키 도움말이 열려 있는 동안과 손잡이로 막대를 끄는 동안에는 접지 않는다. | 메뉴는 막대 밖에 뜬다. 메뉴로 포인터를 옮기는 사이에 막대가 접히면 메뉴의 기준이 사라진다. |
| 접힌 알약의 가로 가운데는 펼친 막대의 가로 가운데와 같다. 기본 자리와 옮긴 자리 모두 그렇다. 저장 값(`dockAt`)의 뜻은 바꾸지 않는다. | 펼칠 때 포인터가 막대 밖으로 밀려나지 않는다. `dockAt`의 가로 값이 이미 막대 가운데다. |
| 범례의 막대 피하기는 접힌 알약의 자리와 크기로 계산한다. 펼친 막대는 범례와 차트 위에 겹쳐 뜨고, 펼치고 접는 동안 범례와 차트는 움직이지 않는다. | 마우스를 올릴 때마다 범례가 오르내리면 안 된다. 디자인 문서의 범례 고정 규칙과 같은 이유다. |
| 폭 전환은 0.16초다. 움직임 줄이기 설정이면 전환 없이 바꾼다. | 짧은 전환은 어디서 펼쳐졌는지 보이게 한다. |
| 연속 그리기가 꺼진 채 도구 하나를 골라 그리는 중에는 평소처럼 접힌다. | 접는 목적이 차트를 가리지 않는 것이다. 한 번 그리면 도구가 풀린다. |
| "연속 그리기가 켜져 있다"는 연속 그리기 버튼이 켜진 것과 도구를 두 번 눌러 그 도구만 연속으로 둔 것을 모두 뜻한다. 둘 중 하나면 막대는 펼친 채로 남는다. | 두 경우 모두 화면에서 "연속"이라고 부르고, 다 그린 뒤 도구가 남는 것이 같다. |
| 연속 그리기가 켜져 있을 때 차트에서 우클릭하거나 Esc를 누르면 그리던 것을 지금처럼 취소하거나 마치고, 연속 그리기 버튼과 그 도구만의 연속을 모두 끄고, 선택 도구로 돌아가고, 막대를 접는다. 이 우클릭은 차트 메뉴를 열지 않는다. | 사용자의 말이다. 한 번의 우클릭이 해제와 메뉴 열기를 함께 하면 해제하려던 손에 메뉴가 뜬다. |
| 해제한 순간 포인터가 막대 밖이면 0.4초를 기다리지 않고 바로 접는다. 포인터가 막대 위면 벗어날 때 접는다. | 해제는 사용자가 방금 한 조작이라 기다릴 까닭이 없다. |
| 연속 그리기가 꺼져 있을 때의 우클릭(차트 메뉴 열기)과 Esc(도구와 선택 풀기)는 그대로 둔다. | 요청이 연속 그리기를 푸는 조작이다. 차트 메뉴는 다른 기능의 입구다. |
| 연속 그리기로 막대가 펼친 채 남는 동안에는 범례가 펼친 막대를 피한다(지금의 막대 피하기와 같다). 마우스를 올려 잠깐 펼친 동안에는 피하지 않는다. | 오래 펼쳐 둔 막대가 범례 글자를 계속 가리면 안 된다. 범례가 움직이는 때는 연속 그리기를 켜고 끄는 순간뿐이다. |
| 연속 그리기 버튼의 값은 지금처럼 저장한다. 켠 채로 새로고침하면 막대가 펼친 채로 열린다. | 저장 방식을 바꾸지 않는다. 우클릭이나 Esc로 끄면 꺼진 값이 저장된다. |
| 막대 위에서의 우클릭(자석 세기 메뉴)은 그대로 둔다. | 해제는 차트에서의 우클릭이다. |
| 접힌 동안 막대 안의 버튼은 키보드와 보조 기술에 닿지 않는다. 알약은 "드로잉 도구 펼치기" 버튼이고 펼침 상태를 알린다. | 보이지 않는 버튼에 초점이 가면 안 된다. |
| 단축키, 손잡이로 옮기기, 고정 도구, 드로잉 스타일 막대는 그대로 둔다. 고정 도구는 펼쳤을 때 보인다. | 요청이 막대를 접는 것이다. |
| 항상 펼쳐 두는 설정은 두지 않는다. | 요청이 "평상시에는 접어둔다"이다. 펼쳐 두고 싶을 때는 연속 그리기가 그 구실을 한다. |

### 2. 목록 서식 통일

| 결정 | 이유 |
|---|---|
| 관심종목의 서식을 기준으로 맞춘다. 이름 14px 굵기 550, 현재가 14px, 등락률은 12px 굵기 550의 색 배지, 줄 높이 34px, 현재가 76px·등락률 60px 열, 열 머리 11px에 선 없음, 고른 줄은 왼쪽 강조색 선과 `surface` 바탕, 줄 사이 선 없음. | 관심종목이 먼저 있었고 본문 글자 크기(14px)를 쓴다. 스크리너를 12px에 맞추면 관심종목이 작아진다. |
| 두 목록의 줄에는 종목 이름만 적는다. 코드와 "지수" 보조 글자는 적지 않는다. 이름이 길면 말줄임표로 자르고, 풍선말(`title`)에 이름과 코드를 적는다. 종목 정보를 아직 못 받았거나 찾을 수 없는 종목은 지금처럼 이름 자리에 코드를 적는다. | 사용자의 말이다. 코드는 풍선말, 줄 메뉴의 머리, 종목 검색에서 볼 수 있다. |
| 종목 칸, 현재가 칸, 등락률 배지, 열 머리의 모양은 두 목록이 함께 쓰는 부품 하나로 둔다. | 따로 두면 다시 어긋난다. |
| 스크리너의 정렬(열 머리 누르기), 잠정 `*`, 옛 일봉 날짜와 관심종목의 열 고르기, 그룹, 끌어서 순서 바꾸기, "실시간 아님" 표시는 그대로 둔다. | 서식이 아니라 기능이다. |
| 휴대폰 폭의 줄 높이와 배치는 각자 지금대로 둔다. 이름만 적는 규칙은 휴대폰에도 적용한다. | 휴대폰의 관심종목은 손가락 크기에 맞춘 다른 배치다. |
| 위 막대의 종목 버튼, 범례, 휴대폰 머리, 종목 검색의 코드는 그대로 둔다. | 요청이 두 목록이다. |

### 3. 스크리너 결과의 줄 메뉴

| 항목 | 동작 | 지금 있는 기능인가 |
|---|---|---|
| 머리 | 이름과 코드 | 관심종목 메뉴와 같다 |
| 이 칸에 열기 (`↵`) | 줄을 누르는 것과 같다. 연동 색을 따른다 | 있다(`openResult`) |
| 비교에 추가 (`Shift+↵`) | 활성 칸의 비교 종목으로 넣는다. 거절 사유는 관심종목과 같은 글귀로 알린다 | 있다(`compareRefusal`, `addCompare`) |
| 관심종목에 넣기 | 목록을 고르는 둘째 메뉴로 바뀐다. 이미 든 목록은 "이미 있음"으로 누를 수 없다 | 한 종목용은 새로 만든다. 저장 동작(`addAll`)은 있다 |
| 종목코드 복사 | 코드를 클립보드에 넣고 알린다 | 새로 만든다 |

| 결정 | 이유 |
|---|---|
| 맨 위로, 그룹, 다른 목록에 복사, 빼기는 넣지 않는다. | 결과는 계산해서 나온 목록이라 순서와 소속을 고칠 수 없다. |
| 우클릭, `Shift+F10`, 메뉴 키로 연다. 데스크톱에만 둔다. 우클릭은 줄에 초점만 주고 칸의 종목은 바꾸지 않는다. | 관심종목과 같은 조작이다. 휴대폰의 관심종목에도 줄 메뉴가 없다. |
| 초점이 결과 줄에 있을 때 `Shift+↵`는 비교에 추가다. | 메뉴에 적은 단축키가 실제로 동작해야 한다. |
| "종목코드 복사"를 관심종목 줄 메뉴에도 넣는다. 머리, 이 칸에 열기, 비교에 추가, 종목코드 복사는 두 메뉴가 같은 코드로 만든다. | 줄에서 코드를 뺐으므로 코드를 꺼낼 길이 두 목록에 같이 있어야 한다. |
| 결과 전체를 관심종목으로 보내는 기존 메뉴는 그대로 둔다. | 줄 메뉴는 한 종목을 다룬다. |

### 4. 거래소 전역 선택

| 결정 | 이유 |
|---|---|
| 거래소는 앱 전체 설정(`UiPrefs`)에 하나를 둔다. 기본은 통합이다. 레이아웃을 바꿔도 그대로다. | 사용자의 말이 "전역"이다. 통합은 지금의 기본 거래소다. |
| 위 막대 오른쪽, 레이아웃 메뉴 앞에 "거래소" 버튼 묶음(통합·KRX·NXT)을 둔다. 휴대폰은 머리의 거래소 묶음이 같은 설정을 바꾼다. | 위 막대 왼쪽의 종목·봉 주기·지표·비교는 활성 칸에만 적용된다. 앱 전체 조작은 레이아웃 메뉴가 있는 오른쪽에 모은다. |
| 범례의 거래소 버튼 묶음을 없앤다. 범례를 꺼도 봉 값 줄 앞에 거래소 선택을 두지 않는다. | 고르는 곳이 한 군데여야 한다. |
| 따르는 곳: 모든 차트 칸의 봉·실시간 현재 봉·세부 봉, 비교 종목, 차트 이미지의 머리와 파일 이름, 휴대폰 머리의 가격, 종목 검색의 작은 차트와 시세, 관심종목 시세. | "모든 UI"다. |
| NXT를 골랐을 때 NXT에서 거래되지 않는 종목은 통합 시세로 보이고, 그 칸의 범례와 관심종목 줄에 "통합" 표시를 붙인다. 앱 전체 설정은 NXT로 남는다. | 주식의 약 78%가 NXT에 없다. 빈 화면보다 통합 시세가 쓸모 있고, 표시가 있으면 섞여 보이지 않는다. |
| 지수는 지금처럼 거래소가 없고 아무 표시도 없다. | ADR 0007의 규칙이다. |
| 스크리너는 따르지 않는다. KRX 일봉 저장소를 그대로 쓰고 결과에는 지금처럼 "KRX"라고 적는다. | 따르게 하려면 통합·NXT 일봉을 전 종목에 대해 따로 모아야 한다. 수집 설계부터 다시 해야 하는 별도 플랜이다(사용자가 정한 결정 7번). |
| 종목 기본 정보와 재무지표는 그대로 둔다. | 거래소별 값이 없다. |
| 처음 여는 값은 통합이다. 레이아웃에 저장돼 있던 칸마다의 거래소는 읽지 않는다. | 칸마다 다른 값을 하나로 줄이는 규칙을 만들면 뜻이 흐려진다. 사용자가 위 막대에서 한 번 고르면 된다. |
| 레이아웃 계약의 `venue` 필드와 DB 열은 남긴다. 웹은 주식 창에 통합, 지수 창에 `null`을 적고, 읽을 때 쓰지 않는다. | 서버와 DB를 고치지 않고 끝난다. 필드를 지우는 것은 되돌리기 어려운 DB 변경이다(사용자가 정한 결정 8번). |
| 주소의 `?symbol=…&venue=…`는 종목을 열면서 앱 전체 거래소를 그 값으로 바꾼다. | 주소로 열었을 때 주소에 적힌 거래소가 보여야 한다. |
| 관심종목 시세는 서버가 거래소를 받아 만든다. 조회(`GET /api/quotes`)와 실시간(`watch`) 모두 거래소를 받고, 시세마다 실제로 쓴 거래소를 함께 돌려준다. 거래소를 주지 않으면 통합이다. | NXT 불가 종목의 대체를 서버가 종목 목록으로 정한다. 웹은 받은 거래소로 "통합" 표시를 붙인다. |
| 이 변경은 새 ADR(0020)로 남기고 ADR 0007의 "칸마다" 부분이 바뀌었다고 적는다. 용어집의 거래소, 통합 시세, 칸, 레이아웃, 범례 항목을 고친다. | ADR 0007이 "다시 꺼내려면 새 ADR로 바꾼다"고 정했다. |

## 작업과 순서

| 작업 ID | 내용 | 고치는 곳 | 시작 조건 |
|---|---|---|---|
| `dock-collapse` | 드로잉 도구 막대를 접고 펼치고, 연속 그리기와 우클릭·Esc 해제를 잇는다 | 웹 | 바로 시작 |
| `list-format` | 관심종목과 스크리너 결과의 줄 서식을 하나로 맞춘다 | 웹 | 바로 시작 |
| `venue-quotes-api` | 시세 조회와 실시간 관심종목 시세가 거래소를 받는다 | 서버, 계약 | 바로 시작 |
| `screener-row-menu` | 스크리너 결과의 줄 메뉴 | 웹 | `list-format` 병합 뒤 |
| `venue-global` | 거래소를 앱 전체 설정으로 옮기고 위 막대에 둔다 | 웹, ADR, 용어집 | `dock-collapse` 병합 뒤 |
| `venue-watch` | 관심종목과 종목 검색의 시세가 앱 전체 거래소를 따른다 | 웹 | `venue-global`, `venue-quotes-api`, `list-format` 병합 뒤 |

```
dock-collapse ──── venue-global ────┐
venue-quotes-api ───────────────────┼── venue-watch
list-format ──┬─────────────────────┘
              └── screener-row-menu
```

순차로 둔 이유:

- `screener-row-menu`는 `list-format` 뒤다. 둘 다 `web/src/features/screener/ResultTable.tsx`의 줄을 다시 짠다.
- `venue-global`은 `dock-collapse` 뒤다. 둘 다 `web/src/chart/legend.ts`의 범례 자리 계산을 고친다(앞의 것은 막대 피하기, 뒤의 것은 머리줄과 봉 값 줄의 거래소 자리). `web/e2e/float-dock.spec.ts`와 `web/e2e/legend-geometry.spec.ts`는 막대와 거래소 버튼을 함께 확인한다.
- `venue-watch`는 세 작업의 결과를 쓴다. 앱 전체 거래소 설정(`venue-global`), 거래소를 받는 시세 계약(`venue-quotes-api`), 통일한 관심종목 줄(`list-format`)이다.

병렬로 둔 이유:

- `dock-collapse`, `list-format`, `venue-quotes-api`는 겹치는 파일이 없다.
- `screener-row-menu`와 `venue-global`은 겹치는 파일이 없다.
- `screener-row-menu`와 `venue-watch`는 `web/src/features/watch/Watchlist.tsx`에 각자 몇 줄을 더한다(앞의 것은 줄 메뉴 항목, 뒤의 것은 "통합" 표시). 두 지시서에 최소 변경으로 하라고 적었다.
- `GLOSSARY.md`와 `docs/design-system.md`는 여러 작업이 서로 다른 항목과 문단을 고친다. 지시서마다 자기 항목만 고치라고 적었다.

## 범위 밖

- 드로잉 도구 막대의 세로 모양, 항상 펼쳐 두는 설정, 드로잉 스타일 막대와 위 막대를 접는 것.
- 연속 그리기가 꺼져 있을 때의 우클릭과 Esc의 뜻을 바꾸는 것.
- 위 막대의 종목 버튼, 범례, 휴대폰 머리, 종목 검색에서 종목코드를 빼는 것.
- 관심종목과 스크리너의 열 구성을 맞추는 것(스크리너에 거래량 열, 관심종목에 정렬).
- 휴대폰의 줄 메뉴.
- 스크리너가 거래소를 따르는 것(거래소별 일봉 저장소).
- 레이아웃 계약과 DB에서 차트 창의 거래소를 지우는 것.
- 알림의 거래소 기준, 종목 기본 정보의 거래소.
- 칸마다 다른 거래소를 나란히 보는 것. 이 플랜으로 없어진다.

|---|---|---|---|---|
| 1 | 접힌 막대의 모양 | 지금 고른 도구의 아이콘이 보이는 알약 | 얇은 띠 | `dock-collapse` |
| 2 | 항상 펼쳐 두는 설정 | 두지 않음. 연속 그리기가 켜져 있는 동안만 펼친 채로 남음(사용자의 말 5번) | 차트 설정의 "항상 펼치기" 스위치 | `dock-collapse` |
| 3 | 목록의 종목 칸 | 이름만 | 이름과 코드 | `list-format` |
| 4 | 통일 서식의 기준 | 관심종목(이름·현재가 14px, 등락률 배지) | 스크리너(전체 12px, 색 글자) | `list-format` |
| 5 | 스크리너 줄 메뉴의 항목 | 이 칸에 열기, 비교에 추가, 관심종목에 넣기, 종목코드 복사 | 항목을 빼거나 더함 | `screener-row-menu` |
| 6 | 위 막대의 거래소 모양 | 버튼 묶음(통합·KRX·NXT) | 펼침 메뉴 | `venue-global` |
| 7 | 스크리너도 거래소를 따르게 할지 | 따르지 않음(KRX 고정) | 거래소별 일봉 저장소를 모으는 별도 플랜 | 없음 |
| 8 | 레이아웃에 저장된 칸마다의 거래소 | 계약과 DB 열은 남기고 쓰지 않음 | 계약과 DB에서 지움 | `venue-global` |
| 9 | NXT를 골랐을 때 NXT에 없는 종목 | 통합 시세로 보이고 "통합" 표시 | 시세를 비우고 "NXT 없음"만 보임 | `venue-global`, `venue-quotes-api`, `venue-watch` |
| 10 | 주소의 `venue=` | 앱 전체 거래소를 바꿈 | 무시함 | `venue-global` |

## 사용자가 정해야 하는 결정

구현을 막는 결정은 남아 있지 않다. 사용자의 말 5번을 화면 동작으로 옮기면서 플래너가 정한 것이 셋 있다. 미리보기에 그대로 들어 있고, 다르게 하려면 `dock-collapse`의 지시서만 고치면 된다.

| # | 물음 | 적용한 것 | 다른 선택지 |
|---|---|---|---|
| 11 | 연속 그리기를 푸는 우클릭이 차트 메뉴도 열지 | 열지 않음. 한 번 더 우클릭하면 메뉴가 열림 | 풀면서 메뉴도 엶 |
| 12 | 연속 그리기가 꺼진 채 도구만 골라 둔 상태의 우클릭 | 지금처럼 차트 메뉴를 엶 | 도구를 풀고 메뉴는 열지 않음 |
| 13 | 연속 그리기 버튼의 값을 새로고침 뒤에도 남길지 | 지금처럼 남김(켠 채로 열면 막대가 펼쳐져 있음) | 새로고침하면 꺼짐 |
