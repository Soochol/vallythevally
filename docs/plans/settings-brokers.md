# 시스템 설정의 여러 증권사·여러 계좌 화면

작성일 2026-11-22. 승인 시점의 기록이며 구현 중 바뀐 것은 반영하지 않는다.

기준: `origin/main` bf10242f. 함께 읽을 플랜: [10호가·호가주문창 UI/UX 개선](ladder-order-ux.md)(키 세 작업), [키움·한투 함께 쓰기](multi-broker.md).

개선안(목업, 고를 것 포함): 오케스트레이터가 게시한 artifact. 원본 HTML은 플랜 초안 폴더의 `settings-brokers.html`이다.

## 사용자가 풀려는 문제

> 시스템설정에서 복수의 증권사와 복수의 계좌를 할 수 있도록 uiux 제안해줘

- 승인된 두 플랜이 시스템 설정을 네 작업에서 나눠 고친다. `kiwoom-keys-settings`(키 목록), `order-accounts`(주문 카드의 계좌별 줄), `source-select-web`(증권사 표시·한투 키·시세 공급원), `kis-orders`(한투 계좌번호·HTS ID). 지시서마다 지금 카드에 덧붙이는 방식이라, 다 들어가면 같은 계좌가 키 목록과 주문 카드에 두 번 나오고 시세 공급원은 줄마다 단추로 흩어진다.
- 이 플랜은 시스템 설정 한 화면의 설계를 먼저 정하고, 그 설계를 네 대기 작업의 지시서에 나눠 넣는다.

## 조사한 것

### 키 하나에 계좌 몇 개인가

- **키움: 키 하나 = 계좌 하나.** `ka00001`(계좌번호)은 `acctNo` 하나만 돌려준다(`crates/server/src/trading/request.rs`). 주문 TR `kt10000`~`kt10003`과 계좌 조회 TR의 요청에는 계좌번호 칸이 없고 토큰이 계좌를 정한다. hoga-ops 실측(`/home/dev/code/hoga-ops/docs/research/2026-10-18-kiwoom-trading/README.md`, `real-account-bindings.json`)에서 키 6개가 서로 다른 계좌 6개를 돌려줬다.
- **키움: 한 계좌에 키 여러 개는 된다.** [ADR 0026](../adr/0026-collector-supervisor-collects-common-and-preferred-stocks.md): "등록 한도는 계좌가 아니라 앱키마다다(2026-11-17 사용자 검증). 그래서 같은 계좌에서 받은 키를 더해도 된다."
- **한투: 키 하나 = 계좌 하나.** 앱키를 계좌마다 신청하고, 계좌번호를 돌려주는 API가 없어 사용자가 넣는다(multi-broker D6, `kis-orders`).
- 그래서 "증권사 → 연결(키) → 계좌"의 연결과 계좌는 늘 1:1이다. 남는 예외는 키움 키 둘이 같은 계좌를 가리키는 경우 하나다.

### 지금 화면과 진행 중인 서버

- 시스템 설정 메뉴는 `web/src/features/system-settings/menus.ts`의 "키움 연결"이 첫 메뉴다. 내용(`KiwoomMenuContent.tsx`)은 연결 상태 카드(`KiwoomStatusCard.tsx`), 키 카드(`KiwoomKeyForm.tsx`), 주문 카드(`KiwoomOrdersCard.tsx`), TR 사용량 카드, 공인 IP 안내 순서다. 메뉴 점은 `kiwoomLink` 상태다.
- 진행 중인 `kiwoom-keys`(새 ADR 0037)가 만드는 API: `GET/POST /api/system/kiwoom/keys`, `DELETE /keys/{id}`, `PUT /keys/{id}/alias`, `PUT /keys/{id}/key`, `POST /keys/{id}/connect|disconnect`, `PUT /api/system/kiwoom/market-key`. 응답 `KiwoomKeyList { limit, keys, keyFileProblem }`, 줄 `KiwoomKey { keyId, alias, broker, source, appKeyTail, market, link }`. 환경 키 별칭은 `ENV_KEY_ALIAS` = "환경 설정 키"이고 바꾸기·지우기가 `EnvReadOnly`로 막힌다.
- 계좌번호 가리기는 호가주문 설정 `OrderSettings.maskAccount`(기본 켜짐)다.

## 확정된 결정

1. 앞선 두 플랜의 확정된 결정을 그대로 따른다. 특히: 시세 공급원은 앱 전체에 하나이고 등록한 연결 가운데 하나다. 주문 계좌는 호가주문창에서 고르고 모든 호가주문창 공통이다. 계좌는 (증권사, 계좌번호)로 식별한다. 순위·시장 개요·투자자는 키움 키가 있으면 키움, 없을 때만 한투다. 주문 사용은 계좌마다 켜고 끝 2자리를 확인한다. 증권사마다 키는 5개까지다.
2. 개선안은 artifact로 보이고, 사용자가 고르지 않은 선택지는 기본안으로 지시서에 넣는다.

## 스스로 정한 결정과 이유

### 정보 구조 (S1 기본안)

- 메뉴 이름을 "키움 연결"에서 **"증권사 · 계좌"**로 바꾼다. 메뉴 ID(`kiwoom`)와 첫 메뉴 자리는 그대로 둔다. 다른 화면의 "시스템 설정 이어가기"가 이 ID로 연다.
- 내용은 위에서부터 **시세 공급원 카드 → 계좌 목록 → TR 사용량 카드 → 공인 IP 안내**다. 주문 카드는 없앤다.
- 계좌 한 줄이 연결(키) 하나다. 키와 계좌가 늘 1:1이라 세 층으로 그리면 가운데 층이 늘 하나뿐이다. 사용자가 고르고 이름 붙이는 대상은 계좌이므로 계좌가 줄이 되고, 키는 그 줄을 펼치면 보인다.
- 계좌 목록은 증권사별로 묶고, 묶음 머리에 증권사 색 칩과 "3 / 5"(개수/상한)를 보인다. 증권사 칩 색은 증권사마다 하나를 정하고 상승·하락색(`--up`/`--down`)과 상태색은 쓰지 않는다(목업은 보라·청록).
- 줄: 상태 점, 별칭, "시세" 표시(시세 공급원이면), `.env` 표시, 계좌번호(끝 2자리만), 주문 사용 표시("주문 켜짐"/"주문 꺼짐"/"계좌 바뀜"), 펼치기.
- 메뉴 점은 시세 공급원 연결의 상태다. 다른 연결에 오류가 있으면 노랑(`amber`)으로 알린다. 시세가 정상인데 메뉴가 빨개지지 않게 하면서도 다른 계좌 오류를 놓치지 않게 한다.

### 시세 공급원 카드 (S2·S3 기본안)

- 시세 공급원은 카드 맨 위의 고르기 상자에서 고른다. 줄에는 "시세" 표시만 둔다. 시세 공급원과 주문 계좌는 다른 축이라는 원칙을 위치로 보인다.
- 고르기 목록은 증권사별로 묶은 모든 연결이다. 연결이 오류인 줄은 흐리게 하고 사유를 붙인다. 고를 수는 있다(서버가 연결 규칙대로 다룬다).
- 고르면 확인 대화상자를 거친다. 문구: 열린 차트·호가·체결을 새로 받는다, (증권사가 바뀌면) 한투는 분봉을 1분봉에서 만들고 실시간은 40건까지다, 순위·시장 개요·투자자를 받는 곳, 주문 계좌는 바뀌지 않는다.
- 카드 안에 지금 연결 상태 카드(`KiwoomStatusCard`)의 내용을 시세 공급원 연결 기준으로 그대로 둔다: 단계, 토큰 만료·실시간 등록·종목 수, 발급 간격 대기, 8050 확인, 연결·끊기, 토큰 파일 다시 확인.
- 카드 맨 아래 한 줄은 "순위·시장 개요·투자자: 키움 · 주계좌"처럼 받는 증권사와 연결이다(multi-broker 확정된 결정 9).

### 계좌 줄 펼치기 (S4·S5·S6 기본안)

- 펼치면 키(앱키 끝 4자리, "화면에서 저장"/".env에서 읽음 · 읽기 전용"), 계좌번호, (한투) HTS ID, 주문 사용, 단추(별칭·키 바꾸기, 지우기)를 보인다. 한 번에 한 줄만 펼친다.
- **주문 사용 켜기·끄기는 줄 안에 둔다.** 키움은 지금 주문 카드 흐름(서버 계좌 확인 → 끝 2자리 표시 → "이 계좌가 맞습니다" → 켜기)이고, 한투는 잔고 조회 성공 뒤 끝 2자리를 직접 다시 입력한다(`kis-orders`).
- **두 키움 키가 같은 계좌면 주문은 한 줄에서만 쓴다.** 두 번째 줄에서 켜기를 확인할 때 서버가 이미 켜진 다른 계좌의 계좌 참조와 비교해, 같으면 켜지 않고 "‘주계좌’와 같은 계좌입니다. 주문은 한 줄에서만 씁니다"로 답한다. 같은 계좌를 두 줄로 주문하면 미체결·명령 기록이 두 갈래가 된다. 그 키는 시세 공급원으로는 쓸 수 있다.
- **키움 계좌번호는 주문 사용을 켤 때 처음 확인한다**(ADR 0029 그대로). 켠 적이 없는 키움 줄의 계좌번호 자리는 "켤 때 확인"이다.
- 바꾸기: 별칭, 앱키·시크릿을 새로 넣는 칸이 열린다. 앱키·시크릿을 비우면 별칭 바꾸기만 보낸다. 키를 바꿔 계좌가 달라지면 그 줄의 주문 사용은 지금 규칙대로 "계좌 바뀜"이다.
- 지우기: 확인 대화상자를 거친다. 시세 공급원이면 다음 시세 공급원(서버 규칙: 남은 첫 연결)을, 주문 사용 중이면 "주문 사용이 꺼지고, 이 계좌를 고른 호가주문창은 시세 공급원 계좌로 돌아갑니다"를 적는다.
- 계좌용 연결의 오류는 그 줄에 사유와 "다시 연결"을 둔다. 8050이면 지금 상태 카드의 두 확인 상자(공인 IP 등록, 반복 발급 잠금 풀림)를 줄 안에 보인다. 발급 간격 대기는 남은 시간을 줄에 보인다. 한투 `OPSP8996`은 저절로 다시 잇지 않고 "다른 프로그램이 이 한투 키로 실시간을 쓰고 있습니다. 그 프로그램을 끈 뒤 다시 연결하세요"와 "다시 연결"을 보인다.

### 계좌 연결 더하기 (S7 기본안)

- 목록 아래 "＋ 계좌 연결 더하기"가 카드 안에서 세 단계 칸을 펼친다. 대화상자를 겹쳐 띄우지 않는다.
  1. **증권사**: 받는 증권사만 칸으로 보인다. 상한에 닿은 증권사는 흐리게 "5개까지입니다". 증권사가 하나뿐이면 이 단계를 건너뛴다.
  2. **입력**: 별칭(기본 "키움 N"/"한투 N", N은 그 증권사의 다음 번호), 앱키, 시크릿, 입력 보기. 한투는 계좌번호(필수, 8자리-2자리)와 HTS ID(선택)를 함께 받는다. 두 칸은 `kis-orders`가 더한다. 그 전(`source-select-web`까지)의 한투 더하기는 앱키·시크릿만 받고, 그 키는 시세 공급원으로만 쓴다. 키움은 공인 IP 안내(지금 `SaveNote`)를 둔다.
  3. **확인**: 저장하면 바로 연결하고 결과(토큰 받음, 한투는 잔고 조회로 계좌 확인)를 보인다. 주문 사용은 켜지 않는다. "주문 사용 켜기로" 단추가 그 줄을 펼친다.
- 서버 오류 문구(같은 앱키, 빈 별칭, 상한, 계좌번호 모양)는 2단계 칸 아래에 보이고 입력을 남긴다. 시크릿은 저장·취소 뒤 지운다(지금 규칙).
- 증권사는 웹의 닫힌 표 하나(`Broker`마다 이름, 칩 색, 입력 칸, 주문 켜기 방식)로 그린다. 증권사가 늘면 이 표에 한 항목을 더한다. 서버가 화면 모양을 내려 주는 방식은 두 증권사에 비해 과하다.

### 그 밖

- **계좌번호 가리기(S9 기본안)**: 시스템 설정은 늘 끝 2자리만 보인다. 여러 계좌가 한 화면에 모이고, 전체 번호는 계좌마다 서버에 따로 물어야 한다.
- **.env 항목(S8 기본안)**: `.env` 키 줄은 ".env" 표시를 붙이고 바꾸기·지우기를 두지 않는다. 별칭은 서버가 정한 "환경 설정 키" 그대로다. 한투 `.env` 계좌번호·HTS ID도 읽기 전용이다. 안내: "바꾸려면 .env에서 해당 줄을 지우세요".
- **모의투자**: 모의 서버에서는 계좌 목록에 환경 키 줄 하나("모의투자" 표시)만 있고, 더하기를 두지 않으며, 시세 공급원은 그 키로 고정이다. 지금 `MockKeyNotice` 문구를 목록 아래에 둔다.
- **휴대폰 폭**: 지금 목록 → 내용 전환 그대로. 계좌 줄은 두 줄(별칭·표시 / 계좌번호·상태)로 접힌다.
- **호가주문창 목록 끝 링크**는 "시스템 설정에서 계좌 관리"이고 이 메뉴를 연다.
- 셋업 마법사는 바꾸지 않는다(두 플랜과 같다).

### 대기 작업에 넣는 방식

새 작업은 없다. 대기 중인 지시서 네 개를 바꾼다. 순서(`after`)와 `paths`는 지금 계획 그대로다. 바꾼 지시서는 플랜 초안 폴더의 `replaced/<작업 ID>.md`에 있고, 오케스트레이터가 `plan rm`/`plan add`로 바꾼다.

| 작업 | 이 플랜으로 바뀌는 것 | 방식 |
|---|---|---|
| `kiwoom-keys-settings` | 메뉴 이름, 시세 공급원 카드(키움 키 가운데 고르기, 확인 대화상자, 상태 카드 내용), 계좌 목록(키움 묶음, 줄 펼치기, 바꾸기·지우기·다시 연결), 더하기(증권사 단계 없이 입력 → 확인), 메뉴 점, 모의투자 모습 | `poteto` 그대로(비밀값 입력·삭제 화면) |
| `order-accounts` | 설정 부분만: 주문 카드를 없애고 줄 안 주문 켜기·끄기, 줄의 계좌 끝 2자리·주문 표시, 같은 계좌 두 키 막기(서버), 지우기 확인 문구, 호가주문창 목록 끝 링크 글자 | `poteto` 그대로 |
| `source-select-web` | 더하기의 증권사 단계, 한투 묶음, 시세 공급원 고르기를 두 증권사로, 확인 대화상자의 한투 제약, 순위·시장 개요·투자자 받는 곳 줄, `OPSP8996` 줄 안 문구 | `poteto` 그대로 |
| `kis-orders` | 설정 부분만: 더하기 2단계의 계좌번호·HTS ID, 3단계의 잔고 조회 결과, 한투 줄 펼치기(계좌번호·HTS ID 바꾸기, 끝 2자리 입력 켜기, HTS ID 없음 안내) | `poteto` 그대로 |

- `order-accounts`의 서버 일(키마다 주문 서비스)과 호가주문창 일, `kis-orders`의 서버 일은 바꾸지 않는다. 같은 계좌 두 키 막기만 `order-accounts` 서버에 더한다.
- `source-select-server`, `kis-client`, 시세 작업들은 바꾸지 않는다.

### 진행 중인 `kiwoom-keys`(서버)와의 관계

충돌하는 결정은 없다. 이 플랜은 그 API를 그대로 쓴다. 맞춰 둘 점만 적는다.

- **시세 키를 고르는 곳**: 지시서 `kiwoom-keys-settings`는 줄마다 "시세용으로"였다. 이 플랜은 카드 위 고르기 상자다. 둘 다 `PUT /api/system/kiwoom/market-key`를 부르므로 서버는 그대로다.
- **.env 키 별칭**: 서버는 "환경 설정 키"로 고정하고 화면에서 바꾸지 못한다(`EnvReadOnly`). 기본안(S8)은 이대로 둔다. 사용자가 다른 안을 고르면 서버 변경이 필요하다. 아래 "사용자가 정해야 하는 결정"의 S8이다.
- **키를 바꿔 계좌가 달라지는 경우**: `PUT /keys/{id}/key`는 키 ID를 유지한 채 앱키를 바꾼다. 다른 계좌의 앱키를 넣으면 같은 줄의 계좌가 바뀐다. 주문 사용은 ADR 0029의 "계좌 바뀜"으로 다루고(`order-accounts`), 화면은 그 줄에 "계좌 바뀜"을 보인다. 서버 변경은 없다.
- **계좌 끝 2자리**: 키 목록 응답에는 계좌가 없다. 줄의 계좌번호와 주문 표시는 `order-accounts`가 계좌 목록(키 ID, 계좌 참조, 끝 2자리, 상태)으로 채운다. 그 전까지 키움 줄의 계좌 자리는 비운다.

## 범위 밖

- 서버 API의 새 경로나 모양 변경(같은 계좌 두 키 막기의 서버 판정 하나만 `order-accounts`에 넣는다)
- 셋업 마법사
- 여러 계좌의 잔고를 한 화면에 합치기, 계좌별 TR 사용량
- 한투 모의투자, 다른 증권사
- 시스템 설정 밖의 화면(호가주문창 계좌 고르기의 모양은 `order-accounts`·`kis-orders` 지시서 그대로이고 목록 끝 링크 글자만 맞춘다)
- 메뉴 ID `kiwoom`, `/api/system/kiwoom*` 이름 바꾸기

## 사용자가 정해야 하는 결정

각 항목의 기본안으로 지시서를 썼다. 다른 안을 고르면 괄호 안 작업의 지시서를 고친다. 검증을 약하게 하는 항목은 없다.

- **S1** 정보 구조: 계좌 중심 한 메뉴 "증권사 · 계좌"(기본) / 증권사마다 메뉴 / 증권사 → 키 → 계좌 세 층. (`kiwoom-keys-settings`, `source-select-web`)
- **S2** 시세 공급원을 고르는 곳: 맨 위 카드의 고르기 상자(기본) / 줄마다 "시세용으로" 단추. (`kiwoom-keys-settings`, `source-select-web`)
- **S3** 시세 공급원을 바꿀 때: 확인 대화상자(기본) / 바로 바꿈. (`kiwoom-keys-settings`, `source-select-web`)
- **S4** 두 키움 키가 같은 계좌: 주문은 한 줄에서만, 두 번째 줄의 켜기를 막음(기본) / 둘 다 켤 수 있음. (`order-accounts`)
- **S5** 키움 계좌번호 끝 2자리를 처음 보이는 때: 주문 사용을 켤 때(기본, ADR 0029 그대로) / 키를 더할 때 `ka00001` 한 번(ADR 0029 개정). (`order-accounts`)
- **S6** 주문 사용 켜기·끄기의 자리: 계좌 줄 안, 주문 카드 없앰(기본) / 따로 주문 카드. (`order-accounts`, `kis-orders`)
- **S7** 한투 계좌번호를 넣는 때: 더하기 2단계에서 함께(기본, 필수) / 나중에 줄에서(시세 전용 한투 키를 계좌번호 없이 넣을 수 있음). (`kis-orders`, `source-select-web`)
- **S8** `.env` 키의 별칭: "환경 설정 키" 고정(기본, 서버 그대로) / 별칭만 화면에서 바꿈. 다른 안은 진행 중인 `kiwoom-keys`의 서버(키 목록 파일에 환경 키 별칭 저장)를 바꿔야 해서, `kiwoom-keys`에 더하거나 새 서버 작업을 `kiwoom-keys-settings` 앞에 둔다.
- **S9** 시스템 설정의 계좌번호 가리기: 늘 가림(기본) / 호가주문 설정 "계좌번호 가리기"를 따름. (`order-accounts`, `kis-orders`)
