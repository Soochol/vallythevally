# 차트 호가 복기는 정리된 날은 수집 저장소에서, 오늘은 수집 자식이 1분마다 쓰는 파일에서 읽는다

[ADR 0025](0025-collector-stores-closed-days-for-the-app.md)는 앱이 수집 자료를 읽는 경계를 `complete.json`이 생긴 뒤(정리된 날)로 묶고, 장중 오늘은 앱 서버의 실시간 원천만 쓰기로 정했다. 차트에서 봉을 가리켜 그 분 끝의 호가·체결을 10호가창·호가주문창에 보여 주는 기능에서는 장중에도 전 종목의 지나간 분 호가가 필요하므로, 이 경계를 호가 복기에 한해 넓힌다(2026-11-24 사용자 결정).

## 정한 것

- **정리된 날**: `store/<YYYYMMDD>/complete.json`이 있는 날은 앱 서버가 수집 저장소의 종목 버킷 Parquet(`0D`·`0B`)을 DuckDB 메모리 연결로 읽기만 해 1분 끝 호가와 분별 마지막 10건 체결을 응답한다.
- **장중 오늘**: 정리가 끝나지 않은 오늘은 공용 자료 폴더(`shared/`)의 분 호가(`quote-minutes-live`), 1분 체결(`trade-minute`), 키 연결 기록(`symbol-flow/<날짜>/links`)을 앱 서버가 읽기만 해 합쳐서 같은 응답 형식으로 준다.
- **읽기 전용과 격리**: 앱 서버는 `VALLY_HOGA_DATA_DIR` 폴더에 쓰지 않고 잠금을 잡지 않으며, 수집기 크레이트를 직접 부르지 않고 문서화된 형식만 읽는다. 다른 시세 경로(키움·공용 자료)와 섞지 않는다.
- **전송 단위**: 화면은 종목·날짜마다 한 번만 받아 마우스를 움직이는 동안 추가 요청을 보내지 않는다. 늘 통합 호가(`_AL`)이며 거래소 인수는 두지 않는다.

## 고르지 않은 안

- **정리된 날만 제공하기**: 장중 차트를 보며 방금 지나간 분의 호가를 바로 복기할 수 없다.
- **서버가 5분 원문 파일(`.jsonl.zst`)을 직접 읽기**: 하루가 지날수록 압축 해제·파싱 비용이 커져 첫 응답 지연과 서버 부하가 커진다. 수집 자식이 1분 단위로 요약해 두는 편이 읽기 비용이 일정하고 작다.

## 결과

- [ADR 0025](0025-collector-stores-closed-days-for-the-app.md)의 "정리 완료 표시 전에는 수집 자료를 읽지 않는다"는 경계에 호가 복기 당일 파일 예외가 생긴다.
- 서버는 `VALLY_HOGA_DATA_DIR`이 설정된 운영자 리스너에서만 `/api/book-replay/*`와 `/api/symbols/{code}/book-replay*`를 연다. 설정이 없으면 기능이 꺼진다.
- 당일 1분 파일 쓰기·읽기는 후속 작업에서 같은 응답 계약 위에 이어 붙인다.
