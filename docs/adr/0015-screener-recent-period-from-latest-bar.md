# 스크리너의 최근 기간은 마지막 봉부터 센다

스크리너는 마지막 봉을 기준으로 최근 얼마 안에 조건이 맞았는지를 찾는다. 봉 위치의 시작과 끝을 따로 지정하는 대신, 마지막 봉을 포함한 실제 봉 개수인 최근 기간 하나를 입력한다. 과거의 중간 구간만 따로 검색하는 표현을 없애고 모든 봉 조건을 같은 기준으로 읽게 한다. 이 결정은 2026-11-12 스크리너 설계 인터뷰에서 확정했다.

최근 기간 N은 1 이상의 정수이며 0~(N-1)봉 전을 뜻한다. 최근 1봉은 마지막 봉 하나, 최근 100봉은 0~99봉 전이다. 새 조건의 기본값은 기존처럼 최근 1봉이다. 실제 존재하는 봉만 세며, 아직 확정되지 않은 현재 봉을 포함한 마지막 봉의 기준은 [ADR 0014](0014-screener-includes-current-krx-day.md)를 따른다.

봉을 사용하는 모든 조건에 적용한다. 입력 순서는 조건 종류, 봉 주기, 최근 기간, 조건별 세부 값이다. 최근 기간은 일봉에서 `최근 [100] 일 이내`, 주봉에서 `최근 [100] 주 이내`, 월봉에서 `최근 [100] 개월 이내`로 표시하며, 마지막 봉을 포함해 센다는 도움말을 제공한다. 예를 들어 `신고가 · 주봉 · 최근 [100] 주 이내 · 고가 [200] 주 신고가`이며, 설명은 `최근 100주 이내에 고가가 200주 신고가를 기록한 봉이 있다`이다. 시가총액 조건에는 봉 주기와 최근 기간이 없다.

최근 기간 안에서 한 봉이라도 맞으면 조건을 충족한다. RSI처럼 상태를 확인하는 조건에도 적용하므로, 최근 100주 중 50주 전에 RSI가 30 이하였으면 지금 RSI가 60이어도 해당 조건을 충족한다. 조건들은 각자의 최근 기간에서 독립적으로 확인하며, 서로 같은 봉에서 맞을 필요는 없다. 결과의 맞은 날짜는 기존처럼 첫 번째 봉 조건이 가장 최근 맞은 봉의 날짜다.

최근 기간은 조건을 확인할 봉을 고르고, 조건별 비교 기간과 지표 기간은 각 후보 봉에서 계산할 값을 정한다. 최근 100주 이내의 200주 신고가는 각 후보 봉을 포함한 200개 주봉을 비교한다. 등락률의 비교 간격과 거래 급증의 평균 기간도 최근 기간과 별개로 유지한다.

기존에 저장한 봉 범위는 끝 위치에 1을 더한 최근 기간으로 자동 변환한다. `0~259`는 최근 260봉으로, `10~19`는 최근 20봉으로 바뀐다. 시작이 0이 아니었던 범위는 마지막 봉까지 확인 대상이 넓어진다. 기존의 최근 M봉 형식은 최근 기간 M으로 유지한다. 이 규칙은 ADR 0014의 임의 봉 범위 지정과 기존 조건식 이전 규칙을 대체한다.
