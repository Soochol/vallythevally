# 백엔드는 Rust로 만들고 Python은 쓰지 않는다

종목 분석 리포트의 전신인 미리보기는 Python으로 작성되어 있다(`docs/research/2026-11-08-samsung-preview/`). 그래도 백엔드는 Rust(Axum) 바이너리 하나로 만들고 Python은 쓰지 않는다. 이유는 속도다. 실시간 체결을 받아 현재 봉과 지표를 계속 다시 계산하고 여러 탭에 나눠 보내는 일을, 한 프로세스 안에서 빠르게 처리하기 위해서다.

Rust를 쓰면 이 설계에서 두 가지를 덤으로 얻는다.

- 지표 계산을 Rust 크레이트 하나에 둔다. 브라우저는 이 크레이트를 WASM으로 받아 차트를 그리고, 서버는 같은 코드로 알림 조건을 계산한다. 구현이 하나라서 같은 입력이면 두 곳의 계산 결과가 같다. 다만 EMA 계열은 입력 길이에 따라 값이 조금 달라지므로, 서버가 알림을 판단할 때 쓰는 봉 수는 설계에서 따로 정한다.
- 서버 하나가 SPA 정적 파일, API, 브라우저용 WebSocket, 키움 연결을 모두 맡는다.

## Consequences

- `docs/research/`의 Python 스크립트는 실행하지 않는 보관 자료다.
- 리포트를 만들 때 미리보기의 계산 로직을 Rust로 옮긴다.
- 옮길 때는 미리보기의 검증 항목과 판정 결과를 정답 테스트로 먼저 고정한다. 예를 들어 2021-01-11 종가 91,000원, 기준금리 결정일 다음 관측일 반영, 해외 지표는 한국 날짜보다 엄격히 이전 값만 쓰는 규칙이 있다. 시차 정렬 규칙은 틀려도 화면에서 드러나지 않기 때문이다.
