# 분기봉은 키움 월봉을 묶고 연봉은 전용 API로 받는다

일반 차트에 분기봉과 연봉을 추가한다. 공식 공개 REST 명세에서 주식·업종지수의 연봉 조회는 확인했지만 분기봉 조회는 찾지 못했다. 분기봉은 같은 종목·거래소의 키움 월봉을 달력 분기별로 묶고, 연봉은 키움의 전용 API로 받는다.

분기봉에 한해 ADR 0003의 다른 봉 주기에서 파생하지 않는 규칙에 예외를 둔다. 별도 시세 원천을 도입하지 않고 키움의 월봉을 그대로 재료로 쓰기 위해서다. 다른 봉 주기의 조회와 캐시 규칙은 ADR 0003을 따른다.

주식 연봉은 `ka10094`, 업종지수 연봉은 `ka20019`를 사용한다. 근거는 [키움 공식 API 스펙](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/c7a3d25449ed4b4238bef378780c41103c67b9e9/kiwoom/_data/kiwoom_api_spec.json)이다.

현재 분기봉·연봉도 실시간 체결로 갱신한다. 분기봉에 필요한 과거 월봉 조회가 실패하면 불완전한 값을 완성된 봉처럼 표시하지 않고 재시도 상태를 보여 준다. 상장 전처럼 원래 자료가 없는 기간과 조회 실패를 구분한다.

이 결정은 2026-11-11 차트 재무지표 설계 인터뷰에서 확정했다. 기능 규칙은 [spec #155](https://github.com/Soochol/vallythevally/issues/155), 인터뷰 이력은 [설계 맵 #154](https://github.com/Soochol/vallythevally/issues/154)에 둔다.
