# 차트 재무지표는 일괄 업데이트한 저장 자료만 읽는다

차트에서 재무지표를 처음 사용하는 종목만 수집하던 방식에서, 코스피·코스닥의 재무자료 지원 회사 전체를 미리 수집하는 방식으로 바꾼다. 차트 조회는 저장 자료만 읽고, 외부 원천 확인은 수동 업데이트와 매일 오전 7시(KST)의 자동 업데이트에서 수행한다. 서버가 꺼져 놓친 확인은 다음 기동 때 수행하되, 사용자 일시정지와 인증 오류에 따른 정지는 명시적으로 재개하기 전까지 유지한다. 호출 한도에 따른 정지는 다음 자동 확인 시각에 확인 요청 하나가 성공해야 재개한다.

초기 수집량과 진행 상태 관리가 늘어나더라도, 차트를 여는 행동이 외부 API 호출을 시작하지 않도록 조회와 업데이트를 분리한다. 수집 중이거나 갱신에 실패해도 마지막 성공 자료를 읽을 수 있으며, 저장 자료가 없으면 미수집으로 표시한다.

재무 원자료는 기존의 독립 SQLite 저장소를 유지한다. 이번 범위는 일괄 수집·저장·차트 표시이며, 재무지표를 이용한 스크리너 조건 검색은 후속으로 분리한다. 보고기간 배치·최신 정정 반영·연결 우선 규칙은 [ADR 0011](0011-financial-indicators-use-reporting-periods.md)을 유지한다.

2026-11-12 설계 인터뷰에서 확정한 방향이다. 세부 규칙·완료 기준·발행한 작업 티켓은 [설계 논의](../financial-collection-design.md)에 기록한다. 기존 [spec #155](https://github.com/Soochol/vallythevally/issues/155)의 규칙 12·수집 완료 기준·후속 변경 절에 반영했으며, 구현은 하위 작업 #227~#231에서 진행한다.
