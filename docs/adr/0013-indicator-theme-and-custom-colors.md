# 지표의 테마 색과 사용자 지정 색을 구분한다

지표의 기존 `ind-1`부터 `ind-5`는 테마를 따르는 색으로 보존하고, 사용자가 직접 고른 색은 검증한 `#RRGGBB` 값으로 저장한다. 기존 색을 모두 HEX로 바꾸면 이후 테마 변경 때 기본 지표 색도 고정되고, 토큰만 저장하면 자유로운 색상 선택을 제한하므로 두 표현을 구분한다. 저장값을 읽을 때 두 표현을 검사하고, UI와 차트와 내보내기에서 같은 색으로 해석한다. 기능 규칙은 [spec #181](https://github.com/Soochol/vallythevally/issues/181)에 둔다.
