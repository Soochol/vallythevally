# 지표 알림은 실시간으로 만든 확정 봉으로 바로 판단하고, 나중에 정정하지 않는다

봉이 확정되면 서버는 실시간 체결로 만든 그 봉으로 지표 알림을 바로 판단한다. 키움 조회로 검증될 때까지 기다리지 않는다.

- 알림이 울릴 때마다 (알림 id, 봉 시작 시각, 봉 출처)를 기록한다. 같은 (알림, 봉)으로는 두 번 울리지 않는다.
- 나중에 봉 출처가 조회한 봉으로 바뀌어 값이 달라지거나, 끊긴 구간을 메우거나, 서버를 다시 켜도 이미 보낸 알림을 정정하거나 소급해 다시 울리지 않는다.
- 알림 기록 화면에는 판단에 쓴 봉 출처를 보여 준다.
- 이동량이 0이 아닌 선(일목균형표 선행스팬 A·B, 후행스팬)은 알림 대상에서 뺀다. 계산 시각과 그려지는 시각이 달라 "언제 교차했는가"가 모호하기 때문이다.

## Considered Options

- **키움 조회로 검증한 봉으로만 판단하기**: 더 정확하다. 하지만 봉이 확정될 때마다 조회 대기열(초당 4회)을 거쳐야 해서 알림이 늦어지고, 대기열이 붐비면 지연이 더 커진다. 실측에서 일봉 거래량이 1분봉 합보다 조금 큰 차이는 확인됐다(docs/kiwoom.md). 그래도 교차 판단이 뒤집히는 일은 드물다고 보고 속도를 택했다.
