# 지표는 범례에서 다루고, 더하는 창은 하나다

사용자가 차트 우측 지표창과 위 막대 지표창이 "너무 어렵고 불편하다"고 했다(2026-11-28). 지표 하나를 다루는 화면이 넷(가운데 창, 차트 옆 인스펙터, 차트 우측 도킹, 범례 팝오버)이었고, 같은 버튼이 도킹이 열려 있는지·저장된 "지표 창" 설정·화면 폭 1280px에 따라 다른 화면을 열었다. Enter와 Esc도 화면마다 뜻이 달랐다. 사용자는 동작하는 시제품을 본 뒤 아래 방향을 승인했다.

## 정한 것

- **지표를 다루는 화면은 셋이다.** 범례 줄, 지표 말풍선, 지표 더하기 창. 가운데 창(`IndicatorCommand`), 차트 옆 인스펙터(`IndicatorInspector`), 차트 우측 도킹(`ChartRightDock`), 이동평균 묶음 편집기, "지표 창" 위치 설정(`UiPrefs.indicatorWindow`)을 없앤다. 저장된 `indicatorWindow` 값은 읽을 때 버린다.
- **범례 줄에서 고친다.** 이름 끝의 숫자는 눌러서 바꾸는 토큰이다. 이름과 토큰은 말풍선을 열고, 줄의 조작은 숨기기와 지우기 둘이다. 패널 접기·순서·합치기·나누기는 말풍선의 "자세히"로 옮긴다. 줄을 끌어 합치고 나누는 동작은 그대로다.
- **더하는 곳은 하나다.** 범례의 ＋지표, 위 막대의 ＋지표, `I`, 명령 찾기, 휴대폰 지표 버튼이 같은 지표 더하기 창을 연다. 위 막대의 비교 버튼은 없애고 종목 비교를 이 창에 둔다.
- **스위치를 끄면 지우고, 다시 켜면 마지막 설정으로 되살린다.** 기억은 칸과 종류별로 메모리에만 두고 저장하지 않는다.
- **Esc는 언제나 닫기만 한다.** 바꾼 값은 남는다. 되돌리기는 Ctrl+Z와 알림의 "되돌리기"다. 말풍선에는 연 때의 값으로 돌리는 "처음 값으로"를 둔다.
- **차트 우측 패널은 지표용으로 두지 않는다.** 사용자가 고정 패널을 남기는 안을 듣고도 없애기를 골랐다. 드로잉 목록은 그리기 도구 막대의 개체 트리에서 연다.
- **위 막대 버튼 이름은 "＋지표"다.**

## 시제품과 다르게 한 것

구현하면서 정한 것이고 사용자에게 알렸다. 사용자가 다르게 정하면 이 절을 고친다.

- **창 종류 `indicators`는 남긴다.** 서버 레이아웃 형식과 [ADR 0031](0031-same-kind-windows-repeat-and-objects-window-is-removed.md)의 "지표만 레이아웃에 하나까지"가 이 종류를 쓴다. 종류를 빼려면 서버 형식과 저장된 레이아웃을 옮겨야 한다. 그래서 창은 남기고 내용만 지표 더하기 창으로 바꾼다. 위 막대의 ＋지표는 이 창을 열거나 앞으로 올리지 않는다(ADR 0031의 `showWindow` 예시에서 지표 "차트 옆"은 더 해당하지 않는다).
- **이동평균은 한 줄로 묶지 않는다.** 시제품은 이동평균을 범례 한 줄에 묶었다. 실제 범례는 십자선 값을 선마다 보이고, 이동평균만 규칙이 다른 것이 불편의 한 원인이었다. 선마다 다른 지표와 같은 줄 규칙을 쓰고, 빠르게 켜고 끄는 일은 더하기 창의 기간 칩이 맡는다.
- **합쳐진 패널의 Y축 배지(R·L·독립)는 범례 줄에 남긴다.** 어느 축을 쓰는지 알려 주는 표시이고 패널을 합쳤을 때만 보인다.
- **종목 비교 줄에는 말풍선을 두지 않는다.** 지금 비교 종목에는 고칠 설정이 없다. 줄의 지우기와 더하기 창의 스위치로 뺀다.

## 그대로 둔 것

- **지표가 셋을 넘으면 "지표 N" 알약으로 접는 규칙은 그대로다.**
- **저장 형식(`ChartSettings`)과 서버 API는 바꾸지 않는다.**

## 따져 본 다른 길

| 길 | 버린 까닭 |
|---|---|
| 우측 도킹을 고쳐 쓴다 | 폭 268~320px 안에 탭·목록·상세가 겹쳐 길을 잃는 구조가 남고, 범례와 같은 일을 두 곳에서 하게 된다 |
| Esc로 되돌리기를 남긴다 | 화면마다 되돌리는 범위가 달라 닫으려다 한 일을 잃었다 |
