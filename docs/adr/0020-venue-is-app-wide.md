# 거래소는 앱 전체에 하나만 고른다

**거래소**(통합·KRX·NXT)는 칸마다 고르지 않고 앱 전체 설정(`UiPrefs.venue`)에 하나만 둔다. 기본은 통합이다. 고르는 곳은 위 막대 오른쪽의 거래소 버튼 묶음과 휴대폰 머리의 묶음이고, 둘 다 같은 값을 바꾼다. 모든 차트 칸의 봉·실시간 현재 봉·세부 봉과 비교 종목, 차트 이미지, 종목 검색의 작은 차트, 10호가창과 호가주문창의 호가·잔량·현재가·사다리 안 체결·거래량이 이 값을 따른다. 사용자가 거래소를 한 번 바꾸면 모든 화면이 그 거래소로 바뀌어야 한다고 정했다(2026-11-16). 이 결정은 ADR 0007의 "칸마다 고른다"를 바꾼다. 거래소별 봉·캐시·실시간에 관한 0007의 나머지는 그대로 유효하다.

(2026-11-23 개정) 시세 공급원도 거래소처럼 앱 전체에 하나다. 공급원을 바꿔도 앱 전체 거래소는 그대로이고, 모든 칸이 새 공급원에서 같은 거래소의 시세를 다시 받는다. [ADR 0043](0043-market-source-is-one-key-of-either-broker-and-switching-drops-the-cache.md).

(2026-11-24 개정) VI 상태는 앱 전체 거래소와 별개로 KRX와 NXT를 나눠 갖는다. 상세정보란 기준가는 KRX 전용이다. [ADR 0049](0049-vi-state-and-static-vi-price.md), [ADR 0050](0050-vi-state-splits-krx-and-nxt.md).

- **NXT 불가 종목**: 앱 전체가 NXT일 때 NXT에서 거래되지 않는 종목의 칸은 통합 시세로 보인다. 앱 전체 설정은 NXT로 남는다. 그 칸의 범례에는 읽기 전용 "통합" 표시가 붙는다. 범례를 끈 칸에서는 봉 값 줄 앞에 둔다. 종목 정보를 아직 받지 못한 동안은 NXT만 통합으로 본다.
- **10호가·호가주문 창**: 두 창은 보이는 거래소의 호가와 체결을 구독하고 거래소가 바뀌면 앞 구독을 놓고 다시 구독한다. 보이는 거래소는 차트 칸과 같은 규칙으로 정한다. 호가주문창의 ⚙ 주문 경로는 주문이 나가는 곳만 정하고 시세를 바꾸지 않는다. 이 두 창의 "통합" 표시는 보이는 거래소가 앱 전체 거래소와 다를 때(NXT 대체)만 붙는다. 프로그램 체결 창과 거래원 입체분석 창은 앱 거래소와 상관없이 통합 값이고 표시를 붙이지 않는다(2026-11-24 사용자 결정).
- **지수**: 거래소가 없고 표시도 없다.
- **스크리너**: 따르지 않는다. KRX 일봉 저장소를 그대로 쓰고 결과의 "KRX" 표기도 그대로 둔다.
- **주소**: `/?symbol=…&venue=…`의 `venue`는 앱 전체 거래소를 바꾼다. 없거나 모르는 값이면 건드리지 않는다.
- **레이아웃 저장**: 칸의 거래소는 저장하지 않고 읽지도 않는다. 레이아웃 계약의 `venue` 필드와 DB 열은 지우지 않고 남긴다. 웹은 저장할 때 주식 창에 `"combined"`, 지수 창에 `null`을 적는다. 이 변환은 저장·복원 경계(`web/src/persist/`) 한 곳에 둔다. 옛 레이아웃의 칸마다 거래소는 무시하고 앱 전체 거래소로 연다.

## Considered Options

아래는 검토했지만 **고르지 않은 안**이다. 다시 꺼내려면 새 ADR로 이 결정을 바꾼다.

- **칸마다 고른다**(ADR 0007): 두 칸에서 KRX와 NXT를 나란히 비교할 수 있다. 하지만 거래소를 바꿀 때 칸마다 눌러야 하고, 관심종목·검색 등 다른 화면과 어긋난다.
- **레이아웃마다 하나**: 레이아웃을 바꾸면 거래소도 바뀌어 "모든 화면이 이 거래소"라는 뜻과 맞지 않는다.
- **레이아웃의 `venue` 필드와 DB 열 삭제**: 서버 계약과 이전 작업이 따라붙는다. 쓰지 않는 필드로 남기는 비용이 더 작다.
- **NXT 불가 종목의 시세를 비운다**: 앱 전체를 NXT로 두면 NXT 불가 종목의 칸이 빈다. 통합 시세로 대신 보이고 표시를 붙이는 쪽이 낫다.
