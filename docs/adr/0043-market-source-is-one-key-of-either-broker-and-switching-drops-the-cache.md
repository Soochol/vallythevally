# 시세 공급원은 키움·한투 키 가운데 하나를 앱 전체에 고르고, 바꾸면 메모리 시세 캐시를 버린다

사용자는 "시세키를 키움, 한투 어느것으로 해도 동작 되도록 해줘"라고 요청했다. 시세 경계([`market_source`](../../crates/server/src/market_source/))와 그 한투 구현([ADR 0039](0039-kis-key-and-token-are-vally-only.md), [ADR 0040](0040-kis-source-builds-minute-bars-from-one-minute-bars-and-reads-the-symbol-master-file.md))은 앞 작업들이 만들었다. 이 ADR은 서버가 시세 공급원을 키움 키나 한투 키 가운데 하나로 고르고 실행 중에 바꾸는 규칙을 정한다. 근거는 [키움·한투 함께 쓰기 플랜](../plans/multi-broker.md)의 "시세 공급원 고르기" 절과 확정된 결정 3·4·9·10이다. [ADR 0037](0037-kiwoom-keys-are-a-list-with-one-market-key.md)의 "증권사에 묶이지 않게 두는 두 원칙"은 이 ADR에서 실제 규칙이 된다.

(2026-11-23 개정) 한투 REST 호출도 공개 사용량의 TR 호출 수에 키움 호출과 합쳐 센다. 한투 스트림은 공급원을 바꾼 직후에도 자리 수(40)보다 많이 등록하지 않는다. 스크리너 갱신은 키움 키가 키 목록에 하나도 없을 때도 거절한다. 등록됐지만 아직 연결되지 않은 키움 키는 거절하지 않는다.

## 결정

- **시세 공급원과 주문 계좌는 다른 축이다.**
  - 시세 공급원은 앱 전체에 하나이고, 등록한 키 가운데 **시세 공급원 키** 하나의 증권사다. 차트·현재가·종목 정보·실시간 시세가 모두 이 키로 온다.
  - 주문 계좌는 호가주문창에서 고르고(`order-accounts`), 시세 공급원을 바꿔도 바뀌지 않는다.
  - 계좌는 (증권사, 계좌번호)로 식별한다. 키 ID에는 증권사를 담지 않는다.
- **키 목록에 증권사가 있다.**
  - 키 목록 파일(`kiwoom-keys.json`)의 항목마다 증권사 칸(`broker`: `kiwoom` 또는 `kis`)이 있다. 칸이 없는 옛 항목은 `kiwoom`으로 읽는다. 알 수 없는 값이면 파일 오류다. 옛 한 개짜리 파일을 옮기는 규칙은 ADR 0037 그대로다.
  - 키는 증권사마다 5개까지다. 환경 키도 그 증권사의 5개에 든다. 같은 앱키를 두 번 등록하지 않는 규칙은 증권사 안에서만 따진다.
  - 환경의 `VALLY_KIS_APP_KEY`·`VALLY_KIS_APP_SECRET`이 있으면 읽기 전용 한투 키 줄이 된다. 키움 환경 키 줄과 같은 규칙이고 키 ID는 `env-kis`다. 키움 환경 키 ID `env`와 겹치지 않게 하려는 것이다.
  - 목록 순서는 키움 환경 키, 한투 환경 키, 파일 키(파일 순서)다.
  - 한투 키도 키마다 토큰 파일·발급 간격·차단 기록이 따로다. 첫 한투 환경 키는 `VALLY_KIS_TOKEN_PATH`(기본 `kis-token.json`)를 쓰고, 화면에서 저장한 한투 키는 앱키 해시 앞 8자를 붙인 `kis-token.<해시>.json`을 쓴다. ADR 0037의 키움 토큰 파일 규칙을 한투에 옮긴 것이다.
  - 모의 투자구분(`VALLY_KIWOOM_ENV=mock`)은 지금처럼 키 목록 파일을 읽지 않고, 한투 환경 키가 있으면 뜨지 않는다([ADR 0030](0030-kiwoom-mock-trading-runs-as-its-own-server-process.md), ADR 0039).
- **시세 공급원 키를 정하는 규칙**
  - 저장은 키 목록 파일의 시세 공급원 키 표시(`marketKeyId`) 하나다. 한투 키 ID여도 된다.
  - 환경 키가 둘 다 있고 고른 적이 없으면 키움 환경 키다.
  - 환경 키가 한투뿐이고 파일 키가 없으면 그 한투 키다.
  - 고른 키가 없어지면 목록의 첫 키다.
- **연결 규칙은 증권사와 상관없이 키마다 같다.**
  - [ADR 0021](0021-kiwoom-connects-only-when-the-user-asks.md)·[ADR 0027](0027-kiwoom-connects-by-itself-when-a-key-is-present.md)의 판단 순서, 자동 연결, 끊어 둠 기억, 차단 기억, 발급 간격 대기를 한투 키에도 적용한다.
  - 한투 키의 판단 순서는 키 확인, 토큰(파일 토큰 재사용, 발급 간격), 시세 공급원 키이면 종목 목록, 실시간, 연결됨이다. 끊어 둠은 그 키의 한투 토큰 파일에 남는다.
  - 한 키의 실패는 다른 키를 멈추지 않는다. 한투 키가 인증 차단, `OPSP8996`, 네트워크 오류로 멈춰도 키움 키는 연결된 채다.
  - 시세 공급원 키가 아닌 키는 계좌·주문과, 한투 키이면 체결통보만 쓴다. 공급원이 키움이 아니면 키움 키의 연결은 종목 목록을 받지 않는다.
- **바꾸면 메모리 시세 캐시를 버린다.** 시세 공급원 키를 바꾸는 절차는 한 번에 하나씩, 이 순서로 돈다.
  1. 옛 공급원의 실시간 시세를 내린다.
  2. 공급원을 새 키로 바꾼다.
  3. 메모리 시세 캐시(봉·현재가·종목 정보)를 모두 버리고, 열린 구독을 새 공급원에 다시 등록한다. 07:45 비우기([ADR 0003](0003-market-data-is-a-cache.md))와 같은 경로이고, 브라우저는 지금의 비우기 알림을 받고 다시 받는다. 순위 캐시, 시장 개요의 투자자 일별 캐시, 장중 표본 표시, 히트맵 시세 캐시, 히트맵 흐름 캐시, 공개 모드 시장 캐시처럼 공급원에 묶인 캐시도 비운다.
  4. 종목 목록을 새 공급원으로 다시 받는다.
  - 발급 간격과 차단 규칙은 우회하지 않는다. 새 공급원 키가 연결되지 않은 상태이면 연결 규칙대로 자동 연결을 시도하고, 끊어 둔 키이면 시도하지 않는다.
- **바꾸는 중 늦게 온 옛 공급원 응답은 캐시에 남지 않는다.** 바꿀 때마다 세대 번호를 하나 올린다. 캐시에 넣는 쪽은 요청을 시작할 때의 세대와 넣을 때의 세대가 같을 때만 넣는다. 봉·현재가·종목 정보 캐시, 순위 캐시, 시장 개요의 투자자 일별 캐시, 장중 표본, 히트맵 시세 캐시, 히트맵 흐름 캐시, 공개 모드 시장 캐시 일곱 곳 모두에 적용한다. 장중 표본은 받는 증권사가 바뀐 시각부터 새 증권사 값으로 이어 쌓는다.
- **공급원은 할 수 있는 기능을 알리고, 웹은 그 집합으로 그린다.** 공급원마다 닫힌 집합 `MarketFeature`가 있다. 서버는 시세 공급원 상태에 이 집합을 싣고, 웹은 증권사 이름이 아니라 서버가 알려 준 집합을 보고 그린다.
- **순위·시장 개요·투자자는 시세 공급원과 상관없이 키움 우선이다**(플랜 확정된 결정 9).
  1. 연결된 키움 키가 있으면 키움으로 받는다. 키 목록에서 먼저 나오는 연결된 키움 키이고, 시세 공급원 키가 아니어도 된다. 그 키움 키의 요청 대기열을 지나므로 우선순위와 한도 규칙([ADR 0035](0035-kiwoom-queue-counts-each-tr-per-second.md))이 같다.
  2. 연결된 키움 키가 없고 연결된 한투 키가 있으면 한투로 받는다. 그 한투 키의 REST 대기열(앱키당 초당 15건, ADR 0039)을 지난다.
  3. 둘 다 없으면 지금처럼 `not_connected`다.
  - 받을 증권사는 요청마다 다시 고른다. 키움 키를 끊으면 다음 요청부터 한투로 가고, 다시 이으면 키움으로 돌아온다.
  - 고른 증권사의 기능 집합에 없는 항목이나 선택값은 증권사에 요청하지 않고 `unsupported_by_source`로 답한다. 한투에는 외국인 연속 순매수 순위, 프로그램 순매수 순위, 연속 매매 카드가 없다.
  - 순위·시장 개요 카드·종목 투자자 응답에 받은 증권사 `source`(`kiwoom` 또는 `kis`)를 싣는다.
  - 장중 표본기([ADR 0034](0034-intraday-market-samples-are-stored-for-the-day.md))도 같은 규칙으로 고른 증권사의 TR을 쓴다. 키움 키가 없으면 한투 TR로 표본을 쌓는다.
- **스크리너 갱신은 연결된 키움 키가 있어야 한다**(플랜 D3). 시세 공급원과 상관없다. 연결된 키움 키가 없으면 갱신 요청을 닫힌 사유로 거절하고, 스크리너 실행과 검색은 그대로 된다. 저장소는 키움 KRX 일봉의 사본 그대로다([ADR 0010](0010-screener-reads-a-disk-daily-store.md)).
- **API**
  - 키 목록 응답의 키마다 증권사와 연결 상태가 있다. 한투 키 줄도 키움 키 줄과 같은 모양이다.
  - 한투 키는 지금의 키 더하기 경로(`POST /api/system/kiwoom/keys`) 본문에 증권사(`broker`, 생략하면 `kiwoom`)를 실어 더한다. 시세 공급원 지정(`PUT /api/system/kiwoom/market-key`)과 키마다 연결·끊기 경로도 한투 키 ID를 받는다.
  - 새 상태 `MarketSourceStatus`는 시세 공급원의 증권사, 키 ID, 별칭, 연결 상태, `MarketFeature` 목록과, 순위·시장 개요·투자자를 받을 증권사와 그 증권사의 기능 집합·종류별 선택값을 담는다. 웹은 요청하기 전에 어느 증권사로 받을지 안다. `GET /api/system/market-source`로 읽고, WebSocket은 연결할 때와 값이 바뀔 때 `MarketSource` 메시지로 보낸다.
  - 지금의 `/api/system/kiwoom*`, `KiwoomLinkStatus`, `kiwoom_link`는 키움 키를 다루는 뜻 그대로 둔다. 셋업 마법사와 지금 화면이 그대로 돈다.
  - 어느 응답에도 시크릿, 전체 앱키, 계좌번호가 없다. 앱키는 끝 4자만 보인다.

## Considered Options

아래는 검토했지만 **고르지 않은 안**이다. 다시 꺼내려면 새 ADR로 이 결정을 바꾼다.

- **키움 키가 있어도 순위·시장 개요·투자자를 한투로 받게 고르는 설정**: 이 세 화면은 키움 열에 맞춰져 있다. 한투 앱키 전체 한도(초당 약 15건)는 차트와 종목 정보에 남겨야 한다. 사용자가 플랜 확정된 결정 9에서 "키움 우선"을 골랐으므로 고르는 설정을 두지 않는다.
- **한 화면에 두 공급원을 나란히 두기**(칸마다 다른 증권사의 시세): 한 화면에서 시각과 값이 조금씩 다른 봉이 섞인다. 실시간 자리(키움 200, 한투 40)와 열린 구독도 공급원 둘로 나눠 세야 한다. 거래소를 앱 전체에 하나 둔 [ADR 0020](0020-venue-is-app-wide.md)처럼, 사용자가 한 번 바꾸면 모든 화면이 함께 바뀌는 쪽을 골랐다.
- **공급원마다 캐시를 따로 두어 섞이지 않게 하기**: 바꾸면 옛 공급원의 실시간을 내리므로, 남겨 둔 옛 캐시의 현재 봉과 현재가는 바로 낡는다. 다시 돌아올 때 그 값을 쓸 수 없어 결국 다시 받아야 한다. 버리는 쪽은 07:45 비우기 경로를 그대로 쓰므로 새 경로가 없다. 공급원을 바꾸는 일은 드물어서 다시 받는 비용도 작다. 늦게 온 옛 응답은 캐시를 나누지 않고 세대 번호로 막는다.

## 결과

- 시세 공급원을 바꾸면 실시간 시세가 잠깐 끊기고, 열린 화면은 07:45 비우기와 같이 새 공급원에서 다시 받는다. 새 공급원 키가 토큰을 새로 받아야 하는데 발급 간격 안이면, 그 간격이 지날 때까지 시세가 없다.
- 시세 공급원이 한투여도 연결된 키움 키가 있으면 순위·시장 개요·투자자는 키움 값이다. 그래서 차트 값과 시각이 조금 다를 수 있다. 웹은 응답의 `source`로 받은 증권사를 알 수 있다.
- 한투 키만 있으면 한투에 없는 세 항목은 `unsupported_by_source`이고 스크리너 갱신은 거절된다. 웹의 안내는 `source-select-web`이 그린다.
- 서버 이전·되돌리기 절차에서 옮길 파일에 한투 토큰 파일(`kis-token*.json`)이 든다([서버 PC 실서버 운영](../server-operations.md)).
- [ADR 0003](0003-market-data-is-a-cache.md), [ADR 0004](0004-dedicated-kiwoom-app-key.md), [ADR 0010](0010-screener-reads-a-disk-daily-store.md), [ADR 0020](0020-venue-is-app-wide.md), [ADR 0037](0037-kiwoom-keys-are-a-list-with-one-market-key.md)에 날짜를 단 개정 줄로 이 문서를 가리킨다.
