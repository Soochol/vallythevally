# 저장소는 공개하고, 실제 시세는 저장소에 남기지 않는다

코드 저장소를 공개한다. 이 도구는 여전히 운영자 한 명만 쓴다(ADR 0001). 코드를 공개하는 것이지 서비스를 공개하는 것이 아니다.

공개 저장소에는 **키움에서 받은 실제 시세를 남기지 않는다.** 키움 약관 제5조③이 시세를 제3자에게 제공하는 것을 금지하기 때문이다. 이 규칙은 커밋, 이슈, PR 본문, 댓글에 모두 적용된다. 구체적으로는 다음과 같다.

- **테스트 고정 입력**: 합성 데이터만 쓴다. 실제 응답의 구조와 형식은 따르되 값은 지어낸다.
- **문서**: 실측 문서(`docs/kiwoom.md` 등)에는 구조, 단위, 규칙, 건수 같은 사실을 남긴다. 가격, 거래량, 거래대금은 예시값으로 쓴다.
- **스크린샷**: 가짜 API(합성 데이터) 화면만 커밋한다.
- **실제 키움 검증**: 로컬에서 계속 한다. 결과는 숫자 없이 "확인함"으로만 남긴다.
- **제3자 원자료**(Yahoo, FRED, 한국은행, NAVER 등): 커밋하지 않는다.
- **커밋 작성자 이메일**: GitHub noreply 주소를 쓴다.
- **라이선스**: MIT.

## Considered Options

- **비공개 유지**: 실제 시세로 검증한 증거를 그대로 남길 수 있다. 하지만 사용자가 공개를 택했다.
- **지금 저장소의 이력을 다시 써서 공개**: GitHub는 PR마다 그 PR의 커밋을 따로 보관한다(`refs/pull/*`). 그래서 `main` 이력을 다시 써도 옛 실제 시세와 원자료가 PR 화면에 남는다. 이 방식은 쓰지 않는다. 대신 정리된 현재 상태로 **새 공개 저장소**를 만들고, 기존 저장소는 비공개 보관소로 남긴다.
