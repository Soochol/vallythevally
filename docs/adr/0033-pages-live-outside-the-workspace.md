# 작업 영역 밖에 페이지를 두고, 작업 영역은 숨기기만 한다

사용자가 hoga-ops의 ETF·시장 종합·히트맵을 vally로 옮기기로 하면서 화면 오른쪽 세로 메뉴를 정했다(2026-11-19). 그 메뉴는 창을 작업 영역에 붙이는 메뉴가 아니다. 아이콘을 누르면 새 화면으로 이동하고, 위 막대의 vally 로고를 누르면 랜딩으로 간다. vally에 작업 영역 밖 화면이 처음 생기므로 그 틀을 정한다. 플랜은 [세로 메뉴와 페이지 플랜](../plans/pages-etf.md)이다.

## 페이지는 창이 아니다

- **페이지**는 자기 주소를 가진 화면이다. 랜딩, 시장 종합, 히트맵, ETF가 있다. **창**([ADR 0019](0019-layout-is-windows-and-placement.md))은 레이아웃에 두고 도킹·캔버스에 놓는 화면이다. 페이지는 창 종류(`web/src/layout/kinds.ts`)에 더하지 않고 레이아웃에도 저장하지 않는다.
- 창이 아닌 이유는 ETF 목록과 상세, 히트맵 타일 지도, 시장 종합의 칸들이 한 화면 전체를 쓰고 창 하나의 크기로는 읽기 어렵기 때문이다. 창으로 만들면 창 종류·배치·저장 모양이 함께 늘어난다.

## 주소

| 페이지 | 주소 |
|---|---|
| 작업 영역 | `/` (지금 그대로) |
| 랜딩 | `/home` |
| 시장 종합 | `/market` |
| 히트맵 | `/heatmap` |
| ETF | `/etf` |

- 새로 고침·뒤로 가기·북마크가 그대로 된다. 세로 메뉴와 로고는 같은 탭에서 그 주소로 이동하는 링크다.
- 페이지 안의 보기 선택(시장·기간, 색 범위, ETF 코드·탭 등)은 주소의 query에 둔다. 새 저장 모델을 만들지 않는다. 작업 영역 밖에서는 `?symbol=`·`?period=`로 활성 칸을 여는 규칙(`useOpenFromAddress`)과 단축키가 꺼진다. 그래서 페이지의 query를 가로채지 않는다.
- 로그아웃 상태에서는 어느 주소로 와도 랜딩이 먼저 보이고 주소는 그대로다. `/collector`와 모르는 주소는 지금처럼 둔다.

## 작업 영역은 숨기기만 한다

- 하나의 라우트 셸이 모든 페이지 주소를 맡는다. 작업 영역(`ChartScreen`)은 다른 페이지에 가 있는 동안에도 언마운트하지 않고 `visibility`로 숨기고 `inert`로 초점과 입력을 막는다. 자리와 크기를 그대로 두므로 차트가 다시 크기를 재지 않는다.
- 그래서 시세 구독과 WebSocket이 이어지고 돌아왔을 때 `/api/bars`를 다시 받지 않는다. 랜딩(`/home`)은 숨긴 작업 영역 위에 덮어서 보인다.
- 세로 메뉴는 데스크톱 폭에서 작업 영역 오른쪽 가장자리를 차지하고 작업 영역 폭을 줄인다. 창 도킹 가장자리는 건드리지 않는다. 휴대폰에는 세로 메뉴가 없다. 페이지 주소로 직접 오면 휴대폰에서도 열리고, 그때는 아래 탭 대신 작업 영역으로 돌아가는 링크를 머리에 둔다.

## 로고와 랜딩

- 위 막대의 vally 로고는 `/home`으로 가는 링크다.
- 로그인 상태(로컬 전용 포함)의 랜딩은 지금 랜딩을 그대로 쓰고, 로그인 단추 자리에 '작업 영역 열기'(`/`)를 두고 첫 화면 아래에 페이지 바로가기 셋을 둔다.

## 종목 보내기

- 페이지가 종목을 보내면 **연동 색**의 차트에 열고 작업 영역(`/`)으로 이동한다. 작업 영역이 숨어 있으면 보내기만 해서는 아무 일도 안 일어난 것처럼 보이기 때문이다. 브라우저 뒤로 가기로 원래 페이지에 돌아온다.
- 보낼 연동 색은 페이지 머리에서 고르고 화면 설정(`ui-state`의 `pageLink`)에 남긴다. 기본은 A이고 끔도 고를 수 있다. 고른 색의 차트가 없거나 끔이면 활성 칸의 차트에 연다. 알림 규칙은 관심종목·스크리너의 `sendSymbol`과 같다.

## 범위 밖

새 창으로 떼기(⇱)와 창 사이 전달, 휴대폰 전용 페이지 입구와 배치는 이번에 정하지 않는다.

## Considered Options

- **페이지마다 라우트를 따로 두고 작업 영역은 `/`에서만 마운트하는 안**: 구현은 단순하지만 페이지에 다녀올 때마다 차트가 다시 불러오고 실시간 구독이 풀렸다 다시 걸린다. 키움 실시간 자리는 한정되어 있어([ADR 0032](0032-book-is-received-per-venue.md)가 다루는 자리 계산) 구독을 쓸데없이 흔들지 않는 쪽을 골랐다.
- **`display: none`으로 작업 영역을 숨기는 안**: 크기가 0이 되어 차트가 다시 크기를 재고 다시 그린다. `visibility`와 `inert`는 크기를 그대로 둔다.
- **시장 종합·히트맵·ETF를 창 종류로 두는 안**: 위 "페이지는 창이 아니다"와 같은 이유로 버렸다.
