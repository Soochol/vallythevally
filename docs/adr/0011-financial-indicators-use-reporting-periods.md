# 차트 재무지표는 보고기간에 배치하고 최신 정정 공시를 따른다

분기봉·연봉의 재무지표는 보고기간끼리 실적을 비교하기 위한 것이다. 1분기 실적이 5월에 공시돼도 1분기에 배치하고, 공시일은 툴팁에 표시한다. 과거 값에는 정정을 반영한 최신 공시를 사용하며, 화면에 이 기준을 명시한다.

결산월이 다른 회사도 보고기간 종료일이 속한 가격봉에 배치한다. 패널에 결산월을 표시하고, 툴팁에는 실제 보고기간을 적는다. 가격봉과 실적의 대상 기간이 다를 수 있다.

공시 시점에 배치하면 주가와 당시 알려진 정보를 비교하기 좋지만, 같은 분기끼리 실적을 비교하기 어렵다. 이 기능은 보고기간을 기준으로 비교하는 쪽을 택한다. 당시 공개된 정보만 쓰는 판정과 주도 사례 리포트의 공시일 축에는 이 결정을 적용하지 않는다. 용어집의 실적 공개 시점 규칙도 유지한다.

재무제표는 연결을 우선한다. 연결재무제표가 없는 회사는 별도를 사용하고 기준을 표시한다. 지배주주 ROE에 필요한 연결 항목이 없으면 일반 ROE로 대체하지 않고 자료 없음으로 표시한다.

조회 실패는 연결재무제표가 없는 경우와 구분한다. 연결 조회 실패를 이유로 별도재무제표로 대체하지 않는다.

연결·별도 기준이 바뀌는 구간은 각 공시값과 기준을 표시한다. 서로 다른 기준의 금액을 차감하거나 합쳐 분기 금액이나 ROE를 만들지 않는다. 결산월 변경으로 짧아진 보고기간이나 한 가격봉에 여러 보고기간이 겹치는 경우도 임의로 합산하지 않고, 툴팁에 원래 값과 표시 불가 사유를 안내한다.

이 결정은 2026-11-11 차트 재무지표 설계 인터뷰에서 확정했다. 기능 규칙은 [spec #155](https://github.com/Soochol/vallythevally/issues/155), 인터뷰 이력은 [설계 맵 #154](https://github.com/Soochol/vallythevally/issues/154)에 둔다. 일반 차트에 적용하며, 정적 주도 사례 리포트 스펙 #137의 규칙은 바꾸지 않는다.
