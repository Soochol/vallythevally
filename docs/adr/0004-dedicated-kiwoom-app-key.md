# 키움 앱키는 vallythevally 전용으로 쓰고, 실계좌 토큰은 서버 한 곳에서만 발급한다

키움 접근토큰을 다시 발급받으면 기존 토큰이 폐기될 수 있다(FAQ25). 또 토큰 하나에 WebSocket 세션은 하나뿐이다(공지 49). 그래서 같은 키로 두 곳에서 토큰을 받으면 서로의 실시간 연결을 끊는다.

- **실계좌 앱키**(`VALLY_KIWOOM_*`)
  - 다른 어떤 프로그램과도 공유하지 않는다.
  - 토큰 발급과 보유는 vallythevally 서버 프로세스 하나만 한다. 로컬에서 운영하는 동안에는 내 PC에서 도는 그 서버다.
  - 스크립트나 테스트는 실계좌 키로 토큰을 발급하지 않는다.
- **모의투자 앱키**(`VALLY_KIWOOM_MOCK_*`)
  - 실측 스크립트, 테스트, 개발 실행에 쓴다.
  - 토큰을 자유롭게 발급해도 된다. 서로 끊기는 일이 생겨도 실계좌 연결에는 영향이 없다.
