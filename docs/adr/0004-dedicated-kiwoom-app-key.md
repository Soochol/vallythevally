# 키움 앱키는 vallythevally 전용으로 쓰고 토큰은 서버 한 곳에서만 발급한다

키움 접근토큰을 다시 발급받으면 기존 토큰이 폐기될 수 있다(FAQ25). 또 토큰 하나에 WebSocket 세션은 하나뿐이다(공지 49). 같은 PC의 hoga-ops도 키움 앱키를 쓰고 있어서, 두 프로그램이 같은 키를 쓰면 서로의 실시간 연결을 끊는다. 그래서 vallythevally는 자기 전용 앱키(`VALLY_KIWOOM_*`)를 쓰고, 토큰 발급은 서버 프로세스 한 곳에서만 한다. 개발 중 단독 실행 스크립트도 토큰을 직접 발급하지 않는다.

- 개발 환경에서는 모의투자 앱키와 녹화된 체결 재생을 쓴다.
- 실계좌 앱키는 이 도구를 운영하는 서버 한 곳에만 둔다. 로컬에서 운영하는 동안에는 그곳이 내 PC다.
