# 운영자 한 명만 쓰는 도구로 운영한다

시세는 키움 오픈 API에서 받는다. 키움 오픈 API 이용약관(2026-06-01 개정) 제5조③은 시세를 "고객이 직접 사용할 목적의 프로그램 개발 등 개인의 업무에 한하여" 쓰게 하고 제3자 제공을 금지한다. 이 조항은 실시간 시세와 지연 시세를 구분하지 않는다. 그래서 이 도구는 운영자 한 명만 쓴다.

- 로그인은 없다. 사용자가 한 명뿐이라 사용자를 구분할 필요가 없다.
- 대신 서버를 외부에 공개하지 않는다.
  - 로컬에서는 `127.0.0.1`에서만 받는다.
  - 클라우드에 올리면 사설망(VPN)으로만 접근한다.
  - 로그인이 없으므로 공개 주소로 열면 누구나 시세를 보게 되고, 그것이 곧 제3자 제공이다.
- 가족과 지인도 제3자다.

원문: https://download.kiwoom.com/deploy/AG001/pdf/AG001_110_20260601.pdf (2026-11-08 확인)

## Considered Options

- **공개 서비스 + 코스콤 정보이용계약 [옵션 3] 웹사이트 체결가서비스용**: 2026-11-08에 확인한 것 중 공개 서비스로 실시간 시세를 보여 줄 수 있는 유일한 경로다. 이용료는 사용자 수와 무관한 정액이지만 금액은 공개되지 않았다. 계약하려면 KRX 승인이 필요하다.
- **공개 서비스 + 공공데이터포털 주식시세 또는 KRX OPEN API 일봉**: 공공데이터포털 쪽은 제3자 제공과 재배포를 금지한다. KRX OPEN API는 비상업 목적에만 쓸 수 있고 제3자 제공도 금지한다.
- **사용자가 자기 키움 키를 연결하는 방식**: 앱키를 위임하는 것을 금지한 제5조②에 걸릴 소지가 있다.

## Consequences

- 이 도구를 공개하려면 먼저 시세 원천을 정식 계약 원천으로 바꿔야 한다. 접근 경로를 여는 것만으로는 공개할 수 없다.
- 판정을 불특정 다수에게 보여 주지 않으므로 유사투자자문업 문제는 생기지 않는다.
