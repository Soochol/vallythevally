# 에코프로비엠 원문 대조와 검토 메모

[#143](https://github.com/Soochol/vallythevally/issues/143)의 에코프로비엠 한 사례를 위한 검증 기록이다. 부모 [#137](https://github.com/Soochol/vallythevally/issues/137)의 생애·실적·섹터·시장·수급을 함께 읽되, 사용자의 영업이익 증가→주도·상승장 대기 가설을 이미 증명된 법칙으로 쓰지 않았다. 원고와 실제 HTML은 사용자 검토 전 초안이다.

## 자료와 재현

수집 도구 기준은 `fb310e66170dbe38cf8c602f9217eb3883cb80bb`다. [#174](https://github.com/Soochol/vallythevally/pull/174)의 DART 원천 대응과 [#176](https://github.com/Soochol/vallythevally/pull/176)의 페이지 저장·지연 근거 펼침이 포함된다. 이 원고 작업은 도구 코드를 바꾸지 않았다. 법인 고유번호 01160363은 공식 corpCode ZIP의 종목코드 247540·에코프로비엠 대응과 실제 공시 목록에서 확인됐다.

```sh
pnpm --dir web install --frozen-lockfile
VALLY_ENV_FILE=<키 파일 경로> node research/leader-cases/collect-bundle.ts \
  --server <승인된 서버 주소> --code 247540 --corp-code 01160363 \
  --from 2016-01-01 --to 2026-11-10
node research/leader-cases/generate-report.ts \
  --manuscript research/leader-cases/manuscripts/247540.json \
  --bundle data/leader-cases/247540/bundle.json
```

실제 수집·원문 조회는 승인받은 분석 단계다. 키움은 서버 관문으로만 조회했고, OpenDART 키는 기존 `readDartKey`로 필요한 값만 읽었다. 계좌·운영정보와 키를 공개 문서에 싣지 않는다. 원자료·Bundle·생성 HTML·진단 스크립트·화면은 git 제외 `data/`와 `target/leader-cases-143/`에 보존한다.

고침 반영 뒤 전체 수집 CLI를 **한 번** 실행해 종료 코드 0으로 저장했다. 버전 2의 페이지 문서를 정상 `readBundle` reader로 열었다. 저장 파일은 71,655,974바이트·426페이지이고 최대 페이지는 6,458,297바이트다. 전체 섹터 지도 309종목과 두 지수, 총 311개 가격 원천이 모두 성공했고 1,794개 가격 API 페이지·1,653,324개 일봉을 보존했다. API가 요청 시작일보다 오래된 이력도 반환하므로 이 총행수는 해석 기간 안의 행수와 다르다. 대상은 2019-03-05~2026-11-10의 1,888일봉이다.

누락 기록은 수급 두 원천의 `kiwoom_starts_later` 두 건뿐이다. 실제 수급도 각각 1,888관측일, 첫날 2019-03-05·마지막 2026-11-10, skippedDays 0·undatedRows 0이다. 2016년부터 요청했지만 상장 전 가격·수급이 없다는 사실을 실패로 메우지 않았다. DART 요청 실패는 0건이며 재무 원장은 분기 48개·연간 12개·공시일 축 31개다. 원장 개수는 모든 계정값이 있다는 뜻이 아니다.

처음 구버전 수집은 저장 전에 실패했다. 그 프로세스 종료 뒤 한 번 실행한 진단은 원천 조회 1,931요청 후 `JSON.stringify(bundle, null, 2)`의 `RangeError: Invalid string length`를 확인했다. 이를 #173/#176으로 분리해 고친 뒤 위의 한 번만 재수집했다. 성공 Bundle은 다시 수집하거나 전체 논리 객체를 단일 JSON 문자열로 만들지 않고 HTML 재생성에 재사용했다.

## 사례 날짜와 읽는 범위

탄생 2020-03-19, 정점 2023-07-25, 소멸 2024-02-07은 사후 선택이다. 현재 수정종가는 각각 13,206원·454,747원·226,881원이다. 탄생은 코로나 급락 뒤 대상승을 되짚은 저점, 정점은 사례 안과 전체 상장 이후의 최고 **일봉 종가** 관측일이다. 소멸은 정점 대비 -50.11%인 상태에서 회사가 4분기 적자·판가와 판매량 감소를 공개한 날로 골랐다. 자동 판정 규칙을 추가하지 않았다.

보고서 해석 범위는 탄생 3년 전 2017-03-19~소멸 1년 뒤 2025-02-07이다. 실적 변곡 후보 2020-Q2가 그 시작보다 앞서지 않아 더 연장하지 않았다. 2019년 이전 연결 비교범위가 불완전하므로 이것이 최초 변곡임을 확정하지 않는다. 상장일은 사업보고서의 2019-03-05로 확인했다. 넓은 원자료 2016-01-01~2026-11-10과 전체 상장 이후 차트 요약은 따로 남겼다. 해석 종료일까지 정점 뒤 최저 수정종가는 2025-01-02의 103,844원(-77.16%)이다.

## #141의 종가·한 분기 직접 대조

[메리츠증권 2023-07-25 마감 시황 원문](https://home.imeritz.com/include/resource/research/WorkFlow/20230725163022491K_02.pdf)의 표를 PDF로 렌더링해 에코프로비엠 종가 **462,000원**을 읽었다. 저장 Bundle의 `prices[symbol=247540].data.daily[day=2023-07-25].c`는 현재 수정종가 **454,747원**이다. 차이는 -7,253원, 비율은 0.9843008658이다. 당시 거래 종가와 현재 수정주가의 기준이 일치하지 않으며, 특정 기업행위의 조정계수로 이 차이를 재현하지 못했다. 따라서 결과는 **기준 미조정 불일치**다. 증권사 작성 원문을 독립 대조한 것이며 거래소 원장을 직접 검증한 것은 아니다. 같은 표의 12MF PER 96.1배·PBR 21.44배는 예측 12개월 배수여서 TTM 밴드 검증에 쓰지 않았다.

분기 영업이익은 [반기보고서 20230814002712](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20230814002712)의 연결 포괄손익계산서 **2023-04-01~06-30, 3개월 열 114,700,920,024원**을 원문 XML에서 읽었다. `dart.financials.quarters[year=2023,quarter=2].single.operatingProfit.value`와 정확히 일치했다. 반기 누적 222,027,923,449원과 구별했고 주식분할로 조정한 계정 금액이 아니다. 공시는 2023-08-14, Bundle의 거래일 축 사용 시작은 2023-08-16이다.

## 원천 종류·접수번호·공개 시점

2023년 말 자기주식 141,263주를 차감한 유통주식수는 97,660,081주다. `stockTotqySttus.se=보통주`, `istc_totqy` 발행수와 `distb_stock_co` 유통수를 구별했다. 2020년 실제 종류 문자열은 `의결권 있는 주식\n(보통주)`다. [20210319000143](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20210319000143) 원문과 Bundle 모두 발행 21,035,166주·자기주식 81,726주·유통 20,953,440주이며 공개 2021-03-19, 사용 시작 2021-03-22다. #174 반영 뒤 정상 값으로 확인했다.

2021년 연간 재무 API 원본 receipt는 [20220321001523](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20220321001523), 공개 2022-03-21, 사용 시작 2022-03-22이며 연간 영업이익 115,031,248,500원이다. 공식 `last_reprt_at=N` 목록에서 회사·종목·사업연도·사업보고서 종류를 확인했고 원본 XML도 읽었다. `last_reprt_at=Y`에 남은 [첨부정정 20220323000828](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20220323000828)은 3/23 공개다. 첨부정정 document 다운로드는 정상 ZIP으로 읽지 못했으므로 그 본문의 계정 변경 여부까지 확인했다고 주장하지 않는다. 원본 receipt를 첨부정정 날짜에 붙이지 않는 #174 결과를 saved Bundle과 HTML의 원문 링크에서 확인했다.

공시일 축은 매칭된 원문의 다음 관측일부터 값을 사용한다. 현재 API의 모든 과거 최초 빈티지를 복원한 것은 아니다. [#175](https://github.com/Soochol/vallythevally/issues/175)의 주식수 차트 지연은 별도 한계다. 이번 saved Bundle에는 `commonShares.availableFrom`이 재무 `availableFrom`보다 앞선 조합이 없어 실제 지연을 재현하지 못했으며 도구를 고치지 않았다.

## 자본·수급·가치평가의 한계

[20220614000068](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20220614000068)의 유상 1,611,344주·발행가 387,600원과 무상 1주당 3주·배정기준일 6/28을 읽었다. 가까운 번호 20220614000070은 증권신고서로 구별했다. [20230718000385](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20230718000385)의 CB 4,400억원·전환청구 시작 2024-07-24는 결정 조건이다. 이를 실제 실행 주식수로 더하지 않았다. 자본 원천 11종이 응답했고 반환 사건 15건의 receipt가 공시 목록과 매칭됐다. 자기주식 계획·정정·실행은 따로 확인해야 하며 해석 범위 뒤 사건도 원자료에 남는다.

수급 조회 깊이 확인은 페이지당 행수·기업행위 전후 수량 조정·외국인 보유비율 분모까지 증명하지 않는다. 분기말 발행주식수와 자기주식 차감 유통수도 매 거래일 EPS 분모를 입증하지 않는다. 기관 누적 순매수는 시작 전 보유량을 모르므로 보유량이 아니다. 당시 거래대금·전체 시장 시총 순위·수급 분모 또는 수정주가와 일치하는 역사 주식수 기준이 불명인 항목은 null로 남겼다. 현재 주식수로 과거 시가총액을 만들거나 종가×거래량을 실제 거래대금으로 대체하지 않았다. PER/PBR·수익률 분해가 불가능한 구간은 선이나 배수를 만들지 않았다.

현재 섹터 지도의 배터리 소재 16종목에는 지주·자회사 경제적 중복과 생존편향이 있다. 각 완료 주의 실제 순위 분모와 신규상장으로 모르는 52주 신고가 개수를 남겼다. 정점 직전 완료 주 2023-07-21 대상 순위는 섹터 안 4/15이지 단기 순위 1위가 아니다.

시장 배경 도구는 누적 종가 고점 대비 20% 하락 조건을 우선 적용한다. 코스닥의 2000-03-10 고점 2,834.4 때문에 2023년 지수 상승·200일선 위에서도 `bear`가 남는다. 이를 상승장이 없었다는 결론이나 사용자 가설 기각에 쓰지 않았다. 별도로 코스닥의 탄생→정점 +119.44%, 2023-01-02→정점 +39.98%를 실제 종가로 기록했다. 배경 띠의 해석은 사용자 검토점이다.
